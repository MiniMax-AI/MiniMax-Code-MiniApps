# 推演口径

本包每一步凭什么这么判。README 只讲这个包做什么、怎么用，推演规则在这里。

**起卦 — 四法择一**
| 方式 | 原理 |
| --- | --- |
| 每日一卦 | 依今日年月日确定性推算，同一天结果不变 |
| 时间起卦 | 年支序加公历月、日为上卦，再加时支序得下卦与动爻，问当下事最合 |
| 数字起卦 | 静心默念两数，第一数为上卦，第二数为下卦，两数之和为动爻 |
| 铜钱摇卦 | 三枚铜钱掷六次，自初爻向上；六为老阴、七少阳、八少阴、九老阳，六与九为动爻 |
**解卦 — 体用生克**
动爻所在经卦为体卦（我），另一经卦为用卦（事）。吉凶只在一处断，只从一个总分来：生克给权重——用生体
+2，体克用与比和 +1，体生用 −1，用克体 −2；再按体卦五行在当月令的旺相休囚死加一减一。总分 ≥2 大吉、
+1 吉、0 平、−1 凶、≤−2 大凶。**生克那一层自己的教科书断语**（体克用作小吉、比和作吉）仍单列出来，
但只作「因」摆在总分旁边，不当第二个答案：页面开头给一个数，紧跟着说清是哪两层把它算成这个数。
原先这两层各说各的，同屏能同时出现「小吉」与「大吉」，看着像算错了。
**四法的变卦快慢**
这一点必须讲明白，否则容易误以为结果写死：
| 起法 | 多久变一次 | 什么情况会再得同一卦 |
| --- | --- | --- |
| 铜钱摇卦 | 每掷一次 | 不会，铜钱随机 |
| 数字起卦 | 换一组数字时 | 填了相同的两个数 |
| 时间起卦 | 每时辰一换，即两小时 | 同一时辰内再起 |
| 每日一卦 | 一天一换，零点即变 | 同一天再起 |
这是术数本来的节律，不是程序在复读。因此每条断语都会在卡片上写明自己的节律：当前取数依据、
下一次何时变；对两种按时取数的，还会直接给出下一次会得到的卦（例如「到巳时再起，将得风火
家人」），你可以看着它转，不必猜。
**所问何事 — 问事定事类与应期**
写在起法上方的问题会落到一个**事类**，再由事类取**类神五行**。这是同一个卦在一天之内能解出不同
侧重的关键：
| 事类 | 类神五行 |
| --- | --- |
| 财运 | 金 |
| 事业功名 | 火 |
| 感情 | 水 |
| 婚恋 | 木 |
| 疾病 | 土 |
| 学业文书 | 木 |
| 房产车契 | 土 |
| 官讼是非 | 金 |
| 出行寻物 | 水 |
**类神只管应期与取象，不改吉凶。** 卦的吉凶仍由体用生克与月令旺衰单独推定，所以同一个卦问财与
问婚，「凶」不会翻面，变的只是应期落在哪几个月日、取象偏重哪一边。认不出事类时不硬套五行，
应期退回按用卦推算，并在断语里说明。
> 这张五行类事表是本包**自订**的类象口径，不是传世定法。梅花易数本身没有六爻那样的六亲用神，
> 本包把京房的六亲与纳甲另起一层给（见下面的「京房一层」），不拿它改体用这一层的吉凶。
**每次十五段起**
卦象总断、动爻爻辞、体用关系、旺衰应期、卦气（当令主卦）、互卦（过程）、变卦（结果）、
错卦（旁支）、综卦（反求）、六亲世应、用神、主客、取象、爻位之象、方所。写了问题会多一段
「所问之事」，讲清落在哪个事类、类神与体卦的生克——也正是有了这句，用神才取得出来。另有三段
按卦出：日辰真冲到爻时多一段「暗动 · 日破 · 冲散」，卦体是六冲或六合、变卦是六冲或有动爻变冲时
多一段「六冲」，有动爻就多一段「化爻 · 变出之爻」，真有反伏或卦变时多一段「反伏与卦变」。所以实际是十七到二十二段。
**动爻爻辞** — 真正动了的那一爻
卦辞说整卦大势，爻辞说的是动在这一爻时的处境，而那一爻正是你的问题落下的位置。三百八十四条
全部入库，解读时只引动爻那一条，不是六条全列——六条会把卦盘压成一堵字墙。爻题照传统记法
（初九、六二、上六），九与六必定与该爻阴阳相合；测试拿三百八十四条逐一比对卦象，错一位就报红。
**动爻象传** — 这一爻凭什么这么读
爻辞是断，象传是据。三百八十四条也整份入库，动爻的那一条以小字排在爻辞下方，并接在同一段
断语里，不另起一段。对校两版时翻出几处两版互有出入、有两处还与通行本相抵触：大有九四该用
「尫」（两版都作「彭」，而爻辞不作），困六三则横跨两版——「蒺藜」取自一版、「不祥」取自
另一版。这些都写进测试钉住，还有需九五的「酒食贞吉」，第二版把它扩成「需于酒食」，与所有其他
来源都不合。
两处最容易被顺手转错的字由测试钉死：损卦的「已事遄往」是已，革卦的「巳日乃革之」是巳；
噬嗑的「噬乾胏」借乾为干，而乾卦的「终日乾乾」说的是刚健，两处不能一并转成「干」。
**彖传** — 这一卦为什么长这样
卦辞说「是什么」，彖传说「凭什么」。六十四卦各有一条，入库后排在卦辞之后、象辞之前，
以一档浅色与左边线示出区别——它是解卦之辞，不是卦本身的原话。长彖传动辄百十字，
乾卦那条最长，自「大哉乾元」一路说到「万国咸宁」，把元亨利贞四字逐层拆开。
对校两版浮出十处实质差异，九处取底本：蒙卦的「初筮告」（另一版作「初噬告」）、
小畜的「健而巽」（另一版漏这四字）、革卦的「革而信之」与「巳日乃孚」都与爻辞自洽。
第十处是乾卦本身，两版一作「保和大和」、一作「保合太和」，按通行本取太和。
这些裁定都写进测试，连同繁简转换的自动推导（用简体来源与繁体底本按位对齐，导出映射表，
只保留一致对子，再人工剔掉三处由来源错字派生出的假对）一并可复现。
**起卦那三秒** — 卦是怎么成出来的
点下起卦，八卦环转起来，旁边逐字打出取数的推演。原先六爻只在结果里出现，推演全程与卦体
无关；现在卦体跟着推演一爻一爻长出来——自初爻向上，长到上爻。**动爻要等六爻都长齐了才
点红**，不能提前：起卦的意义正在于先成卦、再定哪一爻动，提前指出来等于把答案先说了。
时长的正确性由静态测试兜住：等待窗口不得短于推演预算，六爻按最小间隔排下来也必须落在窗口
之内，所以「打字打得完但卦画不完」这种事不会溜过去。系统开了「减少动效」时，六爻一次性
出现，不做生长动画。
**四卦推导** — 互、变、错、综是怎么来的
断语只说「互卦为XX」，看不到怎么互出来的。这一块把本卦摆在上面一行，四种取法的结果摆在
下一行，每一步中间标出怎么取：互卦取二三四为下卦、三四五为上卦；变卦是动爻阴阳反转；错卦
六爻阴阳全反；综卦六爻上下倒置。变卦那一格里，动的那一爻染成朱砂，一眼看出「就是它变了」。
四种取法各有分工——互卦看中间过程，变卦看最终落点，错卦看另一面，综卦看倒影。这四卦不是
四条并列的结论，是同一个问题的四个方向。取法本身由测试逐条核：互卦确为二三四、三四五，错卦
确为全反，综卦确为倒置，变卦只动该动的爻；图上画错一条，测试就报红。
**京房一层** — 六亲、世应与纳甲
这是与梅花并行的一层。梅花以「动爻所在经卦为体」讲**我跟这件事**；京房以「本卦属哪一宫、
第几世」讲六爻各自的身份——哪一爻是我（世），哪一爻是对方（应），每爻在五行生克下是谁的什么。
两套各管一段，不互相替代，所以「世应」这两个字归京房，梅花那层改称「主客」：同一段解读里
出现两个不同的世爻位会看糊涂。
八宫与世次出自《京氏易传》，本包**不抄表**：由八纯卦按爻变规则推——初爻变一世，初二变二世，
初三四变三世，初至四变四世，初至五变五世；五世卦第四爻变回为游魂；游魂卦下三爻收回来为
归魂。推导结果与传世八宫卦序逐一对撞，六十四卦全部吻合。归魂那句最容易记错：收的是游魂的
下三爻，净效果只剩第五爻被变；写成变第四、五爻的话，八个宫的归魂卦会整列变成别宫的二世卦。
测试把这条单独钉住。
纳支用沿用两千年的纳支歌诀原文（乾金甲子外壬午、坎水戊寅外戊申、艮土丙辰外丙戌、
震木庚子外庚午、巽木辛丑外辛未、离火己卯外己酉、坤土乙未外癸丑、兑金丁巳外丁亥），
八条逐一核对。**纳支随经卦走，不随卦宫走**：山水蒙属离宫（阴宫），但下艮上坎都是阳卦，
六爻便全纳阳支。六亲以本宫五行为我——生我者父母、我生者子孙、克我者官鬼、我克者妻财、
同我者兄弟，取地支五行（纳音不在此列）。
世爻一世初、二世二、三世三、四世四、五世五、本宫上爻、游魂四、归魂三；应爻与世爻**配对**
隔三位：初应四、二应五、三应六，返过来四应一、五应二、六应三。照字面写「世 + 3」的话，
本宫卦与五世卦会算到第八、第九爻去——测试专门钉这一条。
卦体上，纳甲那一列直接标在爻位右侧：干支定五行，六亲定身份，世应各用一枚朱砂框标出。
断语里对应多一段「六亲世应」，点出宫与世次、世应两爻的身份、世应之间的生克，以及动爻落在
哪一亲上（财、官、父母……各自管什么，段里一并写明）。变卦另有一套宫与世次，不沿用本卦。
**八宫名单** — 一宫八卦那八个格子
京房这一层最难记的不是「我在哪个宫」，是**那一宫里八卦的次序**。一世到五世世爻逐爻上移，看着像
一架梯子；游魂、归魂两个却往回退（世在四爻、三爻），偏偏又都叫「世」。只写一句「离宫一世卦」，
谁也想不到梯子中间还有两级是倒着走的。
所以同宫八卦全摆成一列，排在四卦推导前头——先认清自己在哪一宫的哪一级，再看梅花那四种推法。
每一格是一枚小卦，标出它相对本宫纯卦变过哪几爻（朱砂）。朱砂框住的是你这一卦，框里那格下面
写的是世次。游魂、归魂那两格的世次加粗，因为它们是梯子上的两个例外，不标出来会看成六个一串。
本卦自己就有落在游魂或归魂上的——十六卦，占全部四分之一。那一格同时挂着「就是你」和「这是
例外级」两个标记，朱砂压过加粗：框和字都朱砂，一看就知道是自己这一卦，同时也知道它是例外级。
小卦上**不标世爻**：世爻在左边卦盘上已经朱砂框出来了，这里再标一遍是两份要人核对的账。
这一列只管次序。
这一列不另抄一张表：拿本宫纯卦作底、按各世次的变爻推出来，与宫、世次是同一套推导，所以八格里
的卦名与次序逐宫跟传世卦序对得上（六十四卦全部吻合）。整份名单连同每格的变爻都是冻结的——
同一宫的八个卦读出来的是同一份数组，看过一次八宫图改了它，后面这一宫别的卦读到的就是被改过的，
而且从哪看出来的都看不出来。
**用神** — 你问的这一件事，落在哪一爻
六亲摆在那里只是摆着，落到「你问的这一件事」上才算用上了。六爻断卦第一步就是取用神：
问何事，取何亲为用神。这一条**有传世定法可依**，与上面五行类事那张自订表不是一回事。
| 所问 | 用神 | 出处 |
| --- | --- | --- |
| 财运、买卖、失物 | 妻财 | 财爻是求测者可以支配、可以到手的资源 |
| 事业功名、官司 | 官鬼 | 官鬼为职位、上司、官非；我克官鬼则我胜 |
| 学业文书、房产车契 | 父母 | 父母为文书、成绩、证照与契据 |
| 感情、婚恋 | 妻财（男占）、官鬼（女占） | 《增删卜易》「男测婚以财为用，女测婚以官为用」 |
| 疾病 | 官鬼为病症，子孙为医药 | 子孙克官鬼，子孙有力则病退 |
| 出行寻物 | 妻财 | 所求之物以财论；寻人须按关系另取，本包不替你猜关系 |
两处刻意的克制：
- **婚恋分男女，本包不替求测者认性别**，所以妻财与官鬼都列出来，由求测者对照自己那一亲
  取。择了其一就等于替他认了性别。
- **占病取两亲**（病症与医药），也是各报所在、不硬择其一。择了就等于替人认了病势。
择爻次序本包**从简为两条：动爻优先，其次取近世爻者**。传世取法更细——两爻俱动取旺相者、
俱静取旺相或临世应者，还要看日辰、旬空、墓库——那些本包不具备条件，就不硬凑一条像模像样
却无法核验的规则。近世取绝对爻位差，不带旺衰，是能核验的那条。
用神不上卦（六亲一个也不在卦里）时，传统从本宫首卦取**伏神**。这一层有明文出处，本包照做。
《增删卜易·飞伏神章第二十八》：
> 若用神不现，即以日月为用神，倘日月非用神者，则于本宫首卦寻之，因本宫首卦，父子财官六亲
> 俱全之故耳。
位置随之而定：本宫首卦里那一亲在第几爻，就伏在本卦的**同一爻之下**；压着它的那一爻是**飞神**。
书上给了两个例证，本包逐字复现——天风姤占妻财，甲寅木伏于姤卦二爻亥水之下；天山遁占子孙，
甲子水伏于遁卦初爻辰土之下。
飞伏之间的生克有四个名字，各自带断：
| 飞伏关系 | 断法 |
| --- | --- |
| 飞来生伏 | 压着它的那爻反倒生它，作吉断 |
| 伏去生飞 | 伏神一味往上供，泄气费力，付出多而收成迟 |
| 伏来克飞 | 伏神一脚踹开压着它的爻，事来得突然而急，多为不吉 |
| 飞来克伏 | 飞神死死压住伏神，所求之事受制，难以出头 |
伏神**出不出得来**是紧接着的一问。《增删卜易》列「易出有六」「终不得出有五」，本包**七条
全部核验得了**——旬空、月破、入墓都按各自的表算。断出来只有出得来与出不来两种：旺衰只走
旺相休囚死五档，旺相必入出、休囚死必入不出，两边已穷尽全部情形。
卦体上用神那一爻另用一枚**实底朱砂**标出（世应用描边框），一眼看出「这件事在这儿」；
伏神则用小字虚框挂在所属爻下，写作「伏 丙子水妻财」。
**元神 · 忌神 · 仇神 — 用神周围那一圈**
取定用神只是头一步。《增删卜易》卷之一**用神元神忌神仇神章第九**把往后的话一并给了，还带金用神
的worked example，断语照它逐条落：
> 元神者，生用神之爻，即为元神。忌神者，克用神之爻也，即为忌神。仇神者，克制元神不能生用神，
> 反生忌神而克害用神，即为仇神。假令金为用神，生金者土也，土为元神；克金者火也，火为忌神；
> 克土生火者木也，木为仇神。余仿此。
三者都在本卦六爻里，一支也不从卦外借：
| | 哪一支 | 作什么 |
| --- | --- | --- |
| 元神 | 生用神的那一爻 | 扶养用神 |
| 忌神 | 克用神的那一爻 | 打击用神 |
| 仇神 | 克元神的那一爻 | 间接为害，见下 |
野鹤接着交代了该看什么，断语就照这三样逐爻报出——哪一爻、动不动、月建旺衰：
> 既得用神，須看旺衰否？有元神動而生扶否？有忌神動而克害否？
**仇神并不直接克用神**，措辞上要留神：它是压着元神叫元神生不动，转头又去生忌神，两头都替
忌神出力。写成「仇神克用神」就把它说反了。这一点立成断言钉住：五种用神之下，仇神都要**反生忌神**
且**不生用神**，少一条都算破。
卦里根本没有的那一支就照实说没有——六爻只纳八个地支，五行里本就常常不齐，宁可写「本卦六爻里没有
这一行」也不从别处借一爻来凑。用神定不下来时没有这一圈：用神取的是卦外伏神，或婚恋那样的两亲
各看各的，都无从取舍。
同章还有一句本包照办：
> 勿以仇神即仇人也
仇神是五行位置上的那一爻，不是卦里那个人。原书把话说尽了：它称作仇人的另有其人——应爻克世。
这一圈也把化爻那头一直只引文、没兑现的后半句接上了：
> 凡遇回頭剋者,徹底剋盡,原用二神遇之則凶,忌仇二神遇之反吉也
有了这一圈，断语才说得出回头克究竟落在哪一支上：落在用神则凶，落在忌神或仇神反不作凶论，落在
元神——书上没讲，就明说没讲，不替它定。四个方向各有断言：落在元神那一支**不许**被断吉凶，用神
那圈压根不存在的卦**不许**硬接这半句。
卦体上三元各标在它自己那一爻，作小字描边，读作「元」「忌」「仇」；忌神用朱砂描边——它是那一圈里
真在直克用神的那一支，元神与仇神则跟伏神一样用淡字。
**暗动 · 日破 — 静爻今天开始动了**
上一节那一圈留了个问题没答，同一本书隔了几章给了答案。野鹤在列完元神、忌神、仇神之后问的是：
> 既得用神，須看旺衰否？有元神動而生扶否？有忌神動而克害否？
「元神有没有动起来生它？忌神有没有动起来克它？」要答这句，还得有第三种动——出自
《增删卜易》卷一·暗动章第二十二：
> 靜爻旺相日辰沖之爲暗動，靜爻休囚日辰沖之爲破。
一句话两半。**静**爻被日辰冲到，于月建旺或相的作**暗动**，休囚或死的作**日破**。这不是边角
情形：六十四卦配十二个月建、十二个日辰、动爻的各种组合扫下来，约 **24%** 的卦里至少有一爻如此
——暗动 10%、日破 14%——而所有逢冲的静爻中 42% 是暗动而非日破。此前本包把静爻一律当静，
「忌神暗动克害用神」「元神暗动生扶用神」这两件——正是这一章的正题——一件也报不出来。
| | 出处 | 怎么算 |
| --- | --- | --- |
| 暗动 | 《增删卜易·暗动章第二十二》 | 静爻，被日辰所冲之支冲到，于月建旺或相 |
| 日破 | 同章，下半句 | 静爻，被日辰所冲之支冲到，于月建休、囚或死 |
章节号取**第二十二**，依卷一目录与传本页题。有二手站标作「025章」，那是全书篇序而非卷内章次，
不从。
只认**静**爻。被冲的爻若本就在动，那是冲散，归动散章第二十三，下一节讲，与本章分列；有断言钉住：
被冲的那一爻一动就从暗动与日破两路里退出去。
旺衰只有五档，两路分尽，不设第三种情形，也不留「无从判」的兜底。由此落出两条结构事实，都是验
出来的不是假设的：日辰只冲一支，而两爻纳支相同（六十四卦里有二十二卦如此，如水雷屯初爻与上爻
同子）时五行必同、旺衰必同，于是必同落一侧——**一卦绝不会既有暗动又有日破**。
**三处本包有意不跟宽法。** 原因就是这一章自己的卦例，本包的判语比那个卦例严：
> 即如寅月乙未日占女痘得坤之師卦…二爻巳火動而克金，得未日沖動丑土，土動生金
这是坤为地、二爻发动，巳火克用神酉金子孙，未日冲动丑土，土遂生金。但丑土在寅月并不旺相，
落在**死**上——照章中字面它该是日破，原文却拿它当救应。实际救得成，是因为巳火是动爻而火生土，
也就是那条静爻得了动爻生扶。这一层细化是合理的，后世也普遍采用，但它不是这一章写下的判语；拿
一个卦例去改定义，等于以个例改通例。本包守住章中定义，并在此说明。测试把整个卦例逐步复现——
坤为地、世在上爻、应在三爻、二爻动变地水师、未冲丑、丑土在寅月落死——并钉死它作日破，
日后若有人按卦例放宽规则，测试会明明白白报出「定义与卦例已经不一致」。
忌的那一路有个异说。传本作「若遇忌神克害用神」，未系「暗动」二字；后世解说多作「忌神暗动克害
用神」。本包取**带「暗动」**的读法——紧挨着的喜路明写「得元神暗動以相生」，且全章题为暗动、
开篇即点「暗動者有喜有忌」，忌路若不含暗动，这一喜一忌就对不上。同段还有半句「忌神明動於卦中，
得元神暗動而生用神」自相矛盾：忌神按定义是克用神的，生不了用神。传本与后世多本都照录未改，
本包不据它另立一条。
断语把整条链摆出来：哪几爻暗动、落在元/忌/仇哪一行，再按书上给两路吉凶——元神暗动相生用神为
喜，忌神暗动克害用神为忌。有两件事本包不做。用神定不下来时没有那一圈，就不挂吉凶。两路吉凶
都写在「用神休囚」这个前提之下，用神旺或相时，断语会说这层前提并不齐备，而不是照套。仇神暗动
两路都不占：这一章的喜忌只分元神与忌神，所以明说书上没讲这一支。
野鹤在本章末尾驳了通行的那句说，断语两句都引：
> 占以暗動福來而不知，禍來而不覺。
> 吉凶之應於動，有急緩之應，則緩非此論，何當不知不覺，報應亦非緩也。
所以暗动不作迟缓读。卦体上暗动作小字「暗」，日破作「日破」，与空、破、墓同一个位置。日破
与月破同族，用朱砂；暗动用淡字——它的吉凶要看这一爻是不是元神或忌神，单看卦体这一格并不知道。
上面野鹤那两句驳的是「暗动迟缓」，所以只在真出了暗动时才摆；一卦若只出冲散，搬这句来就是跑题。
**冲散 — 被日辰冲到的动爻**
紧接着的下一章，《增删卜易》卷一·动散章第二十三，一句就给了判语：
> 占以日辰而沖動爻，謂之沖散。
**动**爻被日辰冲到，就是冲散。这是日辰冲爻的第三条落地路，而且比另外两条加起来还常见：同一批
样本里，约 **24%** 的卦有冲散，暗动 10%、日破 14%。每卦平均 1.05 爻，最多两爻。
三路严格分开。判定先看动不动、再看旺衰，所以一爻绝无可能落进两路，被冲的动爻也绝不会同时被叫
暗动或日破。暗动与日破另外还彼此互斥，理由上一节已经给了：纳支相同的两爻五行必同、旺衰必同，
必同落一侧。
**这一章自己的结论是「不散」。** 野鹤不是光下一个词名，他把自己反复试的结果写了进去：
> 予屢試之，旺相者沖之不散，有气者沖之不散，休囚者間有沖散，亦千百中之一二也。
旺相的爻冲不散，有气的也冲不散；休囚的间或会散，也不过「千百中之一二」。末了落在
「神兆機於動，動必有因」——机子在动上，而动必有因。所以断语**只报事实，不拿它断凶**：逢冲的
动爻若于月建旺相，就点出这一爻并引「旺相者沖之不散」；任何情况下都不说它今日无力、更不据此
断凶。这条有断言钉住——把那句话改写成「该爻今日无力，凶」，测试当场就红。
**豁免是别家给的。**《易冒·日冲章》拿四个字把范围收窄：
> 如動爻遇日辰相沖，苟非月建，則謂之散。
「苟非月建」是豁免：被**月建**冲到的动爻不作冲散，那一路是月破，本包另有其段。所以冲散只由
日辰决定。断言就钉在这一条上，而且钉成可能失败的样子：同一个日辰下换十二个月建，冲散那几爻
一个都不许变；只被月建冲到、日辰没冲到的动爻不许进冲散那一路。
**章里有一部分本包有意不做。**「有气者沖之不散」点了第三种状态「有气」，而全章没说它对应旺衰
五档里的哪一档。《四时旺相章》另有「冲月建之支按休囚、另支留余气」那一条，却没说余气落在哪
一档。照搬要靠猜，猜出来的不是通例，所以只按旺相与休囚两半读。爻动冲爻则是另一回事，要判两
爻谁强，也不在现有口径之内。
卦体上冲散作小字「冲散」，与空、破、墓、暗、日破同一个位置，用淡字加一句悬停说明——不上朱砂，
因为这一章的结论恰恰是**不散**。用神那一圈里，它是第四档「动而逢日冲」，与动、暗动、静并列：
早先只分动静两档，用神自己被冲散也只写成「动」，看不出来。用神圈与断语用神段这两处说法如今
取自同一个共用函数，不会各说各话。
**六冲 · 六合 — 属于整卦的那种冲**
上面这些，都是**日辰**冲到某**一爻**上的。紧接动散章的六冲章第二十，讲的是另一种：装卦本身就
带着的冲。《增删卜易》卷一·六冲章第二十先把六组相冲的支点出来，再数有几种：
> 子午相冲、丑未相冲、寅申相冲、卯酉相冲、辰戌相冲、巳亥相冲。相冲之法有六：日月冲爻者一也，
> 卦逢六冲者二也，六合卦变六冲者三也，冲变六冲者四也。动爻变冲者五也，爻与爻冲者六也。
第一路「日月冲爻」就是日辰月建对着爻，已经在暗动章第二十二与动散章第二十三里逐爻算过。剩下
五路是这一节补的。第四路底本作「冲变六冲」，明天机一系写作「六冲卦变六冲」，指同一件事——变出来
那个卦也是六冲卦——本包取补全的写法。
**配对是初四、二五、三六，数错了就一个都找不着。** 纳甲把内卦三支装在初二三、外卦三支装在四五六，
而两卦的起支错开一位（乾内子寅辰、外午申戌），所以一爻的对位是隔三位，不是同高。按同高去配，
六十四卦里一个六冲卦也出不来。按隔三位配，正好**十个**六冲卦、**八个**六合卦，与传世名单逐一
对得上：
| | 怎么来的 | 名单 |
| --- | --- | --- |
| 六冲卦 | 八纯卦，另加乾坤两卦互易的那两个 | 乾为天、坤为地、天雷无妄、坎为水、离为火、雷天大壮、震为雷、艮为山、巽为风、兑为泽 |
| 六合卦 | — | 地天泰、天地否、雷地豫、山火贲、地雷复、泽水困、火山旅、水泽节 |
乾与震纳甲同支，所以天雷无妄与雷天大壮也是六冲。名单不是抄表，是从纳甲重新算出来再与这份
名单逐个核；核不过就在模块加载时抛错，不会安安静静算出一份不同的名单。
**一组冲，三组必冲。** 世传歌诀说「这三组，只要有一组相冲，其他两组必定相冲，一看就知」。这
不是经验，是装死了的：六支是一串平移的，六组相冲把十二支分成六对互斥的搭档，每一支的冲支唯一，
所以撞上一组就必撞三组。测试拿六十四卦把这一条逐个验过，模块加载时也拒绝在它不成立时启动。
**卦内有零散爻与爻冲，不等于六冲卦。** 六十四卦里有三十卦的两支爻互相冲，其中二十卦根本不是
六冲卦。六冲卦是三对皆冲的整卦结构，零散爻冲是局部的事；混为一谈会把三分之一的卦都说成六冲。
所以零散那几对本包只报事实，不抬到那个身份，也不为它单独开一段。
**章中的判语，以及本包不替人定的那两半。** 冲就是散，散对凶事是好事、对吉事不是——但原书紧接着
自己收了一句「亦必兼用神而言，用神若旺，虽冲不碍；用神失陷，凶而又凶」。后一半判得了，断语就照
用神说：用神定下来，旺或相说这层冲不碍着它，休囚死说这层冲对它不是好事；用神定不下来，就说这一层
不接。另两半只引不套。所问算吉事还是凶事，是问卦人自己心里的定位，一句问题里读不出来，所以两半
都摆上、不替人选；「近病逢冲即愈，久病逢冲则死」要看新病还是久病，只有问的人知道，所以占病只引
这句、不替人选边。唯一接得上的是末了那半句「惟占官非、盗贼、结绝事者宜之」：所问既已认作官讼是
非，这半句说的正是这一类，断语就接；不在此，则明说不是这一类，不替它改判吉凶。
章里对两路卦变都写得极重——六合变六冲是「先合后离、先亲后疏、先浓后淡、始荣终悴、得而复失、
成而后败」，六冲变六冲是「内外变动，交相冲击，必主上下不和，至亲反目，彼此怀奸，始终不就」——
可紧接着又拒不把六冲卦本身断死：
> 古以六冲卦，诸占不吉。予屡试之，用神失陷，实不为吉；用若得地，须以用神断之。
所以六冲卦本身不作凶论，本包也不替它上色：卦体上「六冲」「六合」两枚小标都是淡字描边，不上朱砂。
**把配对画出来。** 「初四、二五、三六」是这一章里看图比读文字更省力的一条规矩：按同高去配，
六十四卦里一个六冲卦都出不来；隔三位去配，十个六冲与八个六合自己就落出来了。所以卦盘把它画
出来——边上三支淡弧各接一对，一律朝外挂。画的是正文反复要强调的那件事：撞在一起的那两支永远
差三行，绝不是并排的。
弧画在两栏之间那道空隙里，不画在卦面上。这一点是试出来的，代价不小：爻画那格是 1fr，凡是要给弧
留的宽度都从它身上扣，而变卦里「回头生 + 应 + 六亲 + 干支」那一行本来就最宽，匀出一格给弧，
那一行的爻画就塌成零，阴阳都读不出来。挪进空隙里，卦面一格宽度都不占。
弧上不挂字。三对是哪三对，右栏「卦体冲合」那一格已经列全；再挂一份就成了要人对着核的第二份账。
每支弧挂一个 `<title>` 写清是哪两支，读屏与查源码的人拿得到。
弧只出现在十八卦上，其余四十六卦一个标也不画。因为三对要么全撞、要么全不撞：全撞的正是那十个
六冲与八个六合，不存在只撞一对的卦，也就无所谓「只画一条」那一路。模块加载时的自校验如今把这条
也钉住了，不再只钉「一组冲则三组皆冲」。
**爻之合 — 合起、合绊、合好、化扶**
六冲与六合那一节讲的是整卦的结构。六合章还有一层落在单爻上，本包原先没做，这轮补上。
章里明写「相合法有六」，六法又分两层：后三法（卦逢六合、六冲变六合、六合变六合）是整卦的
结构，前面已经算过、也在卦体边上画了三支合弧；前三法（日月合爻、爻与爻合、爻动化合）逐爻落地。
「爻之合者，静而逢合，谓之合起；动而逢合，谓之合绊；爻与爻合谓之合好，爻动化合谓之化扶」——
四名由这一爻的动静与合的来路定：
| 名 | 什么时候 | 原书那句 |
| --- | --- | --- |
| 合起 | 静爻合于日辰或月建 | 「得合而起，即使爻值休囚亦有旺相之意」 |
| 合绊 | 动爻合于日辰或月建 | 「动逢合而绊住，反不能动之意」 |
| 合好 | 两爻相合，且**两爻皆动** | 「乃得他来合我，与我和好相助之意」 |
| 化扶 | 动爻化出之爻回头与本爻相合 | 「得他扶助之意」 |
合好有一句明文限定：**「但有一爻不动，亦不为合」**。所以静爻与动爻相合本包不作合好。
章里后文另有「爻静或与日月动爻合者」一句，标点两读：读作「与日月、动爻合者」则静爻也能与
动爻成合，这与上句正面冲突。本包从可核的一读，冲突那一支不取，理由记在代码注释里，不含糊过去。
合好只取不在初四、二五、三六上的配对——那三对属整卦六合，已经画在卦体边上了，在这里再记
一次就是第二份要人核对的账。六十四卦里有二十卦另有这样的相合对（如雷火丰初爻卯与上爻戌、
山水损二四与三五），合好就出在这二十卦上。
**这一层不定吉凶，这是原书自己收的。** 同章三处：「然必用神有气相宜，用若失陷无益」、
「用神受克，六合有何益哉」、末了「宜合吉，不宜合凶」。所以断语只报关系与名目，吉凶仍旧归
用神旺衰那一路；卦体上那个「合」小标与暗动、冲散一样用淡字，不上朱砂——颜色不该替没定吉凶的
东西表态。
跨 365 日 × 256 种摇法（93440 卦）实测：约 **81%** 的卦会出这一段；合绊 52%、化扶 30%、
合起 29%、合好 16%，平均每卦 1.97 爻逢合，最多一卦六爻全逢上。合起与合绊同卦出现的约 12%
（一卦里既有静爻被合起、又有动爻被合绊）。
**爻之刑 — 犯刑**
三刑章第二十一：「寅刑巳、巳刑申、子刑卯、卯刑午、丑戌相刑、未辰相刑。又云：辰午酉亥谓之自刑。」
**照底本六条排，不照命理那套八条。** 两处实质不同：底本作「卯刑午」不作「卯刑子」；底本作
「未辰相刑」一条，不拆成命理那边的「未刑丑、戌刑未」。命理那八条（多出申刑寅、戌刑未、未刑丑、
卯刑子）在六十四卦上碰出 48 卦，底本六条碰出 28 卦。两套混排成十四条，「有几爻犯刑」这个问题就
没有答案了——所以异说记在这里，不并进表里。
**刑有方向。** 丑刑戌在六十四卦上碰出 12 卦，卯刑午只有 8 卦。方向原样带出去，报「谁刑了谁」，
不折成一句「此爻犯刑」——折了就看不出是谁动的。
**自刑四支里，辰一支在爻与爻那路上一次也碰不着。** 这不是漏做，是结构上的事实：辰只装在内卦三爻
（乾内子寅辰、坎内寅辰午、艮内辰午申），一卦只有一个下卦，所以一卦里最多出现一个辰，碰不出
「本支见本支」。午、酉、亥三支都碰得出（各 8、6、8 卦）。辰这一支并不是死的——月建逢辰、卦里
又有辰爻时，「月建自刑辰爻」照样成立，365 日里有 4.2% 的卦走这一路。模块加载时的自校验把
「自刑辰在爻与爻那路上恒为 0」钉死，免得日后有人当成漏做再加回来。
三路都报：爻与爻相刑、本支见本支的自刑、日月与爻相刑。自刑本就对称，同一对只报一次——
两头都收的话，断语会把「二爻亥自刑四爻」与「四爻亥自刑二爻」并排说一遍，看着像两件事。
相刑那六条有方向，不受这条约束。书上那个卦例能逐字复现——寅月申日风火家人
变离卦，月建寅刑五爻巳、日辰申被五爻巳所刑，两路正落在同一爻上（那一爻正是子孙）。
**这一层不定吉凶，而且依据是原书自己收的。**「夫三刑者，予屡试之，或因用神休囚又兼他爻犯之，
刑者则见凶，而独犯三刑得验者少，占过数十年只验得一卦。」野鹤自己试了几十年，单靠犯刑只验中一卦。
所以断语只报「谁刑了谁」，再把「用神休囚」与「又兼他爻犯之」那两条前提逐条核一遍，成立不成立
都照实说，吉凶仍旧归用神旺衰。卦体上那个「刑」小标与「合」一样用淡字，不上朱砂。
实测（数字起卦 19800 次）：约 **90%** 的卦会出这一段；按六十四卦 × 365 日（23360 次）另扫一遍是
90.7%，两者对得上。其中爻与爻那路 58%、日月与爻那路 80%，平均每卦 1.05 爻犯刑，最多三爻。
**有意没做的：卦身与世身。** 传统卦盘上多有这两样，本包一件也不画。不是漏了：本包底本是
《增删卜易》，而删掉它们正是这本书自陈的特色——「删除卦身世身、星煞本命，使人无歧路之虞」。
《卜筮全书》《卜筮正宗》录其名而不用，韩艺所传连三易又极重世身，后世分成三路。一个以《增删卜易》
为骨干的包，再加一层骨干删掉的东西，等于跟自己的底本打架。判法记在这里备用——阳世从初爻起子、
阴世起午，数到世爻那一支便是卦身；世身按世爻地支定爻位，子午居初、丑未居二、寅申居三、卯酉居四、
辰戌居五、巳亥居六——但不画，也不拿来断任何事。
**反伏与卦变 — 同一件事的两头会翻面**
反伏章第二十五开头就把两件事摆在一起，但它们各自的条件对不上，所以本包分成两档报，不合成一条：
> 卦有卦變，爻有爻變。卦變者內外動而反伏者同一卦也。如乾卦變坤卦。爻變者內外爻動而反伏者，非同一卦也。
> 如升之觀是也。又有外卦反伏而內卦不動者，如觀之坤是也。又有內卦反伏而外卦不動者如巽之觀是也
**反伏那一档：内卦或外卦的纳支，被整体换成与之逐位六冲的那一组。** 章里三例都对得上这一条——
观之坤动五六，只有外纳支换了；巽之观动二三，只有内纳支换了；升之观动二、三、五、六，内外都换了。
换过去的那一组，无一例外都是本卦那一组的逐位六冲（观之外卦巽的未巳卯换成坤的丑亥酉，一支一支都对得上冲）。
本包照这一条判，内卦、外卦各判一次，所以「只内反」「只外反」「内外都反」三种情形分得清，
不用一句「此卦反伏」糊过去。六十四卦配六十三种非空动静共 4032 种，这一档落在 252 种上
（内外都反 4、只内反 124、只外反 124）。
**卦变那一档：六爻全动，且本卦与变卦都是八纯卦。** 章里第一句举的乾变坤，纳支逐位**一个都不冲**
（子对未、寅对巳、辰对卯），所以它不属于上面那一档——它属于的显然是「同一卦」那四个字：乾坤、坎离、
震巽、艮兑，两两相对。「全动」这一条不能省：乾只动初、四两爻也变得到巽为风，两头都是八纯卦，
可那一爻没动全，谈不上章里说的「內外動」。全量扫下来这一档八种，与反伏那一档**交集为零**——
合成一条的话，乾变坤要么被漏掉，要么得为了它把反伏的判据放宽到不再可核。模块加载时的自校验把
「两档交集为零」与「252 + 8 = 260 种」一并钉死。
**三档各有各的那一句，本包不替你择。** 内外都反伏时，章里「內卦反伏，我亂他定」与「外卦反伏，他亂我定」
两句都沾得上，断语明说两句都对得上，不挑一句念。
**这一层不定吉凶，依据是原书自己给的。** 章末那句把话说死了：
> 反伏卦用神旺相不變沖克者則反復，事之必成，第恐用神而化回頭之沖克者，卽是卦變大凶之象。
两条都以用神为轴，所以断语只把两条前提核出来——「用神旺相」那条核用神于月建的旺衰，
「用神化回头冲克」那条核用神本爻动不动、变出来的那一爻克不克本爻——成立不成立都照实说，
**「事之必成」不许当无条件判词**。取不出用神时第一条压根核不了，断语明说缺哪一层，不空谈。
**章里那十条分占只接所问事类对得上的那几条。** 占功名、占财物、占墳墓宅捨、占婚姻、占疾病、占盗贼官非、
占出行各归本包一类事类（恋爱与婚嫁共用「占婚姻」那一条），「占彼此」那一路按内卦外卦分开引。
占天时与占行人两桩本包没有对应的事类，接不住就明说接不住，不拿别的占法来顶。
实测（手掷铜钱）：出这一段的约 **6.4%**，档位分布为内卦 47.7%、外卦 47.7%、内外都反 1.5%、卦变 3.1%。
**时间起卦、每日一卦、数字起卦三种起法出这一段是 0**——不是漏做，是那三法照梅花易数本来的规矩只动一爻
（动爻由总数除六取余，只有一爻），而反伏至少要动两爻、卦变要六爻全动，条件上就碰不着。
实测 9125 次，零命中；六十四卦 × 63 种动静 × 31 个采样日共 124992 次，6.4%。
**有意没做的：卦体上的反伏小标。** 空、破、墓、暗、日破、冲、合、刑都挂在单爻上，反伏与卦变挂不了——
它们说的是本卦与变卦之间的关系，不是某一爻的处境，挂到单爻上会指错地方。所以只进断语与 MCP 抬头。
**六神 — 日干说出的这件事的调子**
六爻卦盘上人人都会画的那一列。《卜筮全书·卷之一·启蒙节要》：
> 甲乙起青龍，丙丁起朱雀，戊日起勾陳，己日起螣蛇，庚辛起白虎，壬癸起玄武。（俱從下起至上。）
日干定的是**初爻**起哪一神，自初爻往上按固定次序转：青龙、朱雀、勾陈、螣蛇、白虎、玄武，转满
六个再回头。歌诀原文入库，与紧随其后的六行排列表逐格对撞——甲乙、丙丁、庚辛、壬癸两两同干，
共三十二格。同章的两个乾为天卦例也逐爻对过：甲子日子水子孙临青龙，戊子日同一爻临勾陈。
| 六神 | 五行 | 所主 |
| --- | --- | --- |
| 青龙 | 木 | 喜庆、喜事、贵人、酒色、正直 |
| 朱雀 | 火 | 口舌、文书、消息、是非、诉讼 |
| 勾陈 | 土 | 田土、房产、牵连、迟滞、牢狱 |
| 螣蛇 | 火 | 怪异、虚惊、缠绕、噩梦、欺诈 |
| 白虎 | 金 | 凶险、血光、伤病、丧事、威猛 |
| 玄武 | 水 | 暗昧、盗贼、隐私、暧昧、欺瞒 |
螣蛇的五行有异说，通行本多作火，亦有作阴土者。本包取**火**并写明：取土则与勾陈同，而
「虚惊」与「迟滞」本是两件事，取错便说反了。
有一条本包不许越的界，断语每次提到六神都把这句摊开：
> 吉凶全凭五行生克，情态方看六神吉凶。
六神**不参与生克、不改吉凶**，它只说这件事是什么性质、什么气氛。测试拿同一个卦在二十八天里
各起一次卦——初爻所临之神换过好几轮——吉凶必须一个字都不动。
**化爻 · 变出之爻 — 动爻往哪儿去**
京房这一层的最后一块：动爻不是它自己了，它在变卦里变出另一支纳支。变出来的这一支与原来那支
是什么关系，就是化爻的全部。
| | 是什么 | 怎么论 |
| --- | --- | --- |
| 回头生 | 变爻生本爻 | 吉 |
| 回头克 | 变爻克本爻 | 凶 |
| 化泄 | 本爻生变爻 | 只陈事实，不配吉凶 |
| 化耗 | 本爻克变爻 | 只陈事实，不配吉凶 |
| 化比和 | 同行 | 只陈事实，不配吉凶 |
两个名目由原话钉死，而两个方向分得清楚：
> 巽木变坎水，谓之化生，水回头以生木也，即以吉断。
> 震木变乾金，谓之化克，金回头以克木也，即以凶推。
两句都只看一个方向——**变爻对本爻**。《卜筮正宗·十八问答第二问》把回头克的五种情形逐个点出来：
> 土爻動而變木、木爻動而變金、金爻動而變火、火爻動而變水、水爻動而變土，此是爻之回頭剋也
正好落在「变爻克本爻」的全部五个五行组合上，一个不多一个不少。这张表在本包里是当**定义校验**
用的（`HUI_TOU_KE_PAIRS`），模块加载时逐对与生克表对撞，定义不能与代码走偏。同章还有一句，
它让回头克不只是个平铺的凶：
> 凡遇回頭剋者,徹底剋盡,原用二神遇之則凶,忌仇二神遇之反吉也
所以断语每次都把「彻底克尽」这半句带出来：回头克落在用神身上则凶，落在忌神仇神身上反吉。
另三类**不配**吉凶——《增删卜易》给了名目却没定吉凶，硬配就成了编。
**进退神**是它在地支那一层的搭档，出自《增删卜易·进退神章第二十九》：
> 进神：亥化子，寅化卯，巳化午，申化酉，丑化辰，辰化未，未化戌，戍化丑。
> 退神：子化亥，卯化寅，午化巳，酉化申，辰化丑，未化辰，戍化未，丑化戍。
十六对、两个方向，每对同行、互为反面。其中四对在土上（丑→辰→未→戌→丑，这圈上前后各走一步），
这是歌诀本来就密，不是笔误。歌诀里没有的不判。变爻自身的化空、化墓只作**事实**报告，不配
吉凶：野鹤讲空讲的是「动爻逢空」那一层，书上并没有「变爻逢空即凶」这样的断语。
这一层有一条规矩把边界划死，断语在给出任何结论之前先把它摊开：
> 夫變出之爻，能生克沖合本位之動爻，不能生克他爻，而他爻與本位之動爻，亦不能生克變爻。
变爻只跟本位动爻相生克，不跟他爻相干，也不跟世爻应爻攀关系。还有一条容易踩的：变爻在变卦里
是**静**的那一爻，不许把「发动」「得动爻生扶」这些救应算到它头上——它占的爻位恰好就是动爻
那位，一混就会把本该落的真空悄悄翻成假空。
**旬空 · 月破 · 入墓 — 这一天的日子对每一爻做了什么**
这三样压在京房的纳甲之上，决定一爻今天还算不算数。
| | 出处 | 怎么算 |
| --- | --- | --- |
| 旬空 | 《增删卜易·旬空章第二十六》 | 歌诀六句原文入库，与算法逐句对撞。天干十位配十二支，一旬十日总有两支配不上天干，那两支便是空。 |
| 月破 | 《增删卜易》「月破者，月建冲爻之谓」 | 月建冲本爻，与「正月申破」到「十二月未破」的月表一致。 |
| 入墓 | 《纳甲筮法讲义·生旺墓绝》 | 取自墓一支：金墓丑、木墓未、水土墓辰、火墓戌。 |
| 绝地 | —— | 不出结果，且不是漏做。绝是墓的下一支（金绝寅、木绝申、水土绝巳、火绝亥），可纳甲里每个五行只占两支——金申酉、木寅卯、水子亥、火巳午、土丑辰未戌——上列绝支没有一支落在五行自己占的支里，六十四卦任何一爻都落不上。「绝」这一标据此撤掉，而不是留一个永远不会亮的字；`jingfang.mjs` 加载时核这个事实，将来一旦不成立就在这里抛。 |
空有真假，野鹤自己分得清楚，断语照他的原话逐条落，不另立规矩：
> 旺不爲空，動不爲空，有日建動爻生扶者不爲空，動而化空、伏而旺相皆不爲空。月破爲空。
> 有卦不動爲空，爻反伏而被克爲空，真空爲空，真空卽春土、夏金、秋木、三冬逢火是真空。
**假空**是这个空不作数：旺、动、得日辰或动爻生扶、动而化空、伏而旺相任一条都能救它，
出旬或逢冲之后照旧有力。**真空**是这一旬里真没用：月破，或逢四季所空的那一行
（春空土、夏空金、秋空木、三冬空火），或伏而被克。卦体上分得清——假空作「空假」，真空作「空真」。
有一处取舍照实说明，不藏着：野鹤原文作「有卦不動爲空」，后世多本作「有氣無動爲空」，
差一个「氣」字，意思是「静卦全空」还是「静而有气者空」两样。本包取**后者**——
同段前一句「旺不爲空」若被推翻便无处容身，取前者自相矛盾。
每一爻在卦体上各有一个小标：空、破、墓、暗、日破、冲散；右栏另有一格把当旬旬首、空亡两支与本月所破
的地支直接摊开。
只逢月破、不逢旬空的爻同样作真空，依据就是同段那句「月破爲空」。早先这里出的是「暂看不出真假，
等出旬或逢冲之日再定」——两处都不对：书上明写的一条凭据被搁下了，而「等逢冲」更是与月破章
正相反：
> 雖現於卦，有亦如無；伏於卦中，終難透露。即有日辰之生，亦不能生。
所以月破这一句改成「待出月、逢值再论」，不再提逢冲——出月、逢值才救得回来，冲只会伤得更重。
只逢旬空而不月破的爻仍是「等出旬逢值或逢冲再论」，那一路的空，冲一下确实能解。
**卦气 · 当令主卦** — 当月该由哪一卦说话
汉易以十二卦配十二月，称十二辟卦：复主子月、临主丑月，直到坤主亥月。它与「旺衰应期」
那条不是一回事——那条看的是五行在月令里强弱，这条看的是卦象随节气的消长。复至乾是息卦，
阳爻自初爻逐次上升；姤至坤是消卦，阴爻自初爻逐次上升。一年就这么转一圈。
断语会点出本月主卦，并说明本卦是否正在十二辟卦之中：若本卦也在息卦那一段，方向与时势
相合；若分处消长两端，就是逆着时势走，宜放缓一步。十二辟卦只占六十四卦中的十二个，其余
五十二卦不论卦气——不硬套。
**消长环** — 上面这套理论画出来是什么样子
十二辟卦是抽象的，一个环把它摊开：环分十二格，每格一卦，每格画 N 条短杠，N 就是那一月
长了几爻。复一爻长到乾六爻是阳气到底，折回姤一爻再长到坤六爻是阴气到底，走完一圈是一年。
走到对宫就是极盛——子午、卯酉那两条虚线就是标这个的。
当月那一格高亮；若你这一卦正在十二辟卦之中，环上会点一个朱砂点标出它的位置。环放在断语
之前：断语是结论，这个环是结论背后的时令坐标，先看得到形状，再读「当月主卦是哪一卦」，
就不至于只是一句话。系统开了「减少动效」时，当月格的呼吸动画会停掉。
**应期** — 事情何时应
取类神（认出事类时）或用卦（未认出时）五行的旺相之地。乾金为用卦，旺在申酉、相在亥子丑，
断语便指向申酉月与申酉日。
**爻位之象** — 动爻位置的含义
初爻事在萌芽、位未显；二爻近身而仍受制；三爻内外之交，是进退转换之关；四爻近人多惧；
五爻君位，多见贵人；上爻事至终局。
**方所** — 方位
取体卦与用卦的后天八卦方位，问寻物问路可取。
体卦得势但用卦耗你时，断语不会只给一个干脆的「吉」，而是补一句「方向可进，力气要省」。
**卦库 — 六十四卦**
可按卦名或上下卦检索，查看卦辞、彖传、象辞与互卦、错卦、综卦。
**历法**
年月日时四柱干支、十二时辰及其黄道黑道、建除十二神、二十四节气、数九、十二生肖三合六合。
**卦历**
保存的卦象存于本机，起卦后可补一句批注，按时间倒序，最多 500 条，可单独删除。写了所问就用所问
当卦题，没写则按起法命名（今日之卦 / 此刻之卦 / 心中之卦 / 手掷之卦）。
**在对话里起卦 — MCP 端点**
本包同时向 Agent 提供一个 MCP（streamable-http）端点 `/mcp/divination`，可以不打开页面直接在对话里
起卦，三个工具分别是 `divination_cast`（起卦解读）、`divination_hexagram_lookup`（检索六十四卦）、
`divination_almanac`（今日干支历法）。
**本包自己不调任何模型、不出站。** Agent 本身就是模型，由它调用本端点、再用自己的语言讲卦——
密钥、计费与上下文都留在会话里，本包只负责「算得对」。
参数、返回格式、怎么触发、排障：见上面的[在对话里起卦（MCP）](#在对话里起卦mcp)。

## 算法口径

- 算法口径：日柱由儒略日推算，与传世万年历一致（2000 年 1 月 1 日为戊午日）；月支取最近一个
  「节」，节气日期为常年近似值，可能差一日；年支以立春为界，立春近似取 2 月 4 日。本包不含
  农历年历，不换算农历日期，也未声称支持。
- 时间起卦的月、日取公历，这是通行的现代简化（古法用农历），应用会在「起卦依据」中写明，
  不作隐藏。
- 节律有测试兜底：同一时辰内起卦与跨时辰起卦各测一次，并核对「预告的下一时辰之卦」与真的
  到了那个时辰起卦的结果一致。
