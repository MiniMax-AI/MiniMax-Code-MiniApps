# Cutline for MiniMax Code

[English](README.md)

本地视频剪辑器，保留上游 19 个 Agent 工具，另增加一个工程目录导入工具和一个独立导出工具。插件内直接包含固定版本 FableCut 1.16.0 源码，无需单独安装 FableCut 或拉取 Git 子模块。可以手动操作时间线，也可以在聊天里让 Agent 导入素材、剪辑、添加字幕与动效、处理音频和导出。

Cutline 是面向 MiniMax Code 的 [FableCut](https://github.com/ronak-create/FableCut) 社区改编版，不是 FableCut 官方版本，也未获上游项目背书。

## 安装与打开

在 MiniMax Code 中将本目录作为本地 Plugin 安装，保留隐藏的 `.minimax-plugin` 目录。随后从 Mini App 入口选择 Cutline，或让 Agent 打开它。服务由 Host 管理，无需手动启动服务器或访问固定端口。

媒体分析、代理文件、音频处理和视频编码需要运行环境的 PATH 中存在 `ffmpeg` 和 `ffprobe`。插件不捆绑这些程序；请安装适合操作系统的版本，修改 PATH 后重启应用。

附带的 `cutline` Skill 说明各项编辑操作及其对应的工具调用。

## 功能范围

Cutline 处理的是媒体：导入视频、音频与图片，铺到时间线上，再渲染成片。

内置媒体生成不在本插件范围内：没有图片、视频、语音或音乐的生成步骤，插件也不配置供应商密钥。新素材与其他素材一样以导入文件的方式进入时间线——通过 `fablecut_import_media` 或工程目录导入。

## 界面语言

编辑器界面提供英文与简体中文两种语言。在**设置 → 外观 → 语言**中切换。切换立即生效——不需要重载，也不会改动工程——选择结果只保存在当前浏览器的 `localStorage` 的 `fablecut-locale` 键里。不会向任何地方发送数据：两份词典就是编辑器自带的本地文件（`miniapp/client/i18n-en.js` 与 `miniapp/client/i18n-zh-CN.js`），编辑器不会为它们发起网络请求。

首次打开时编辑器跟随浏览器语言：浏览器语言为 `zh*` 时用中文，其他情况用英文。一旦手动选择过，就以你的选择为准。

**已翻译**：外壳、菜单、悬浮提示、无障碍名称与占位文本、设置与帮助对话框、工程面板、素材库及其筛选、时间线及其右键菜单、检查器、调音台、调色页、导出对话框与进度、确认提示与消息提示。

**有意不翻译**：

- **你输入的文字。**工程名、素材名、片段名、工程备注、自存模板的分组名以及模板字段里填入的值，在任何语言下都逐字节保持原样——即使它们看起来和我们的词条一样（"Settings"、"Export"、"Color"）。编辑器不会把这些文字交给翻译器。
- **技术取值。**轨道与片段 id、存储的枚举值、文件名、编码/封装/色彩空间名称、像素格式与 ffmpeg 参数都保持原样。枚举值显示时只翻译旁边的标签，存储值本身不变，因此在一种语言里写好的工程换一种语言打开也没问题。
- **开发者与服务器错误细节。**`[FableCut] …` 开头的行以及服务器原始报错保持英文，方便按原样阅读问题报告。
- **最终出现在画面里的文字。**字幕、标题与模板自带的内容取自工程，不取自界面语言，因此两种语言下导出的画面完全一致。

## 工具名称

21 个面向 Agent 的工具中，20 个沿用上游名称：`fablecut_status`、`fablecut_get_project`、`fablecut_import_media`、`fablecut_export` 等；第 21 个是本包自带的独立导出工具 `cutline_export`。插件、Mini App 与 Skill 使用 Cutline 品牌，但上游工具本身沿用上游名称，这样以后同步上游更新时无需重命名公开工具接口。MCP 服务本身注册为 `cutline`，接口路径为 `/mcp/cutline`。

## 使用方式

- 打开 Mini App，调用 `fablecut_status` 确认当前工程。
- 按需读取 `fablecut_docs` 的具体章节，通过 `fablecut_get_project {compact:true}` 查看时间线。
- 用 `fablecut_import_media` 导入本地文件，再用返回的媒体 ID 创建片段。
- 优先用 `fablecut_patch_project` 局部编辑。依赖已读版本的修改带上 `baseRevision`，遇到冲突重新读取当前工程。
- 用 `fablecut_set_project` 替换完整文档时，必须传入 `fablecut_get_project` 返回的 `baseRevision`。提交文档和原样的基线版本号即可；写入成功后由服务端递增存储版本，不要自行递增文档里的 `revision`。
- 用 `fablecut_versions` 管理版本，用 `fablecut_projects` 管理工程。
- `fablecut_import_project {folder}` 会复制已有工程的媒体，保存当前工程版本后替换当前时间线，原件不变。缺失、越界或不受支持的非媒体文件会使导入被拒绝，支持源媒体子目录。页面中的纯 JSON 导入不会自动带入外部媒体。
- 合成画面抽帧、示波器、跟踪和导出需要编辑器页面保持打开。长任务使用 `wait:false` 后按 job ID 查询。

### 本地文件与绝对路径

MCP 工具以启动应用的那个人的权限运行，并不限于插件自己的目录。

- 接受 `path` 参数的工具——`fablecut_import_media`、`fablecut_analyze_reference`、`fablecut_frame`——会解析绝对路径并直接读取该文件。**用户能读到的任何文件都能这样被读到**；这里没有目录白名单，也没有沙箱。只使用用户明确指出的路径。
- `fablecut_import_media` 会把文件复制进私有数据目录，原件保持不动；工程引用的是这份副本。
- `fablecut_import_project {folder}` 会读取磁盘上任意一个用户能读到的工程文件夹，把它引用到的媒体与素材库文件复制进私有数据目录，并把导入的文档保存为当前工程。原文件不会被修改。

服务在多个会话之间共享，上游工程管理沿用一个全局当前工程。切换工程会影响其他打开的页面；编辑前应核对当前工程并协调切换。

## 两种导出方式

`fablecut_export` 在 Mini App 面板里打开的编辑器页面中渲染：用户能看到进度条，导出占用编辑器的任务位，一次渲染可以产出多个文件，但 Mini App 需要保持打开。

`cutline_export` 是本包自带的工具，它不渲染，而是**准备**一个任务并把精确路径交给 Agent：

- Mini App 把已保存的工程、工程引用到的全部媒体与素材库文件、编辑器前端、渲染运行时和一个独立运行器，复制到私有数据目录下的新任务文件夹里。复制逐字节进行，不使用硬链接；源文件缺失或指向工程目录之外时，任务在可运行之前就被拒绝。
- Agent 用自己的后台 shell 工具，在该后台任务的前台启动这个运行器：`node "<任务目录>/runner/runner.mjs" --job "<任务目录>"`。
- 运行器在自己的临时回环端口上提供编辑器副本，端口由它本次运行生成的密钥保护，并用无头 Chrome 或 Edge 驱动它。渲染用的是编辑器自带的 Fast export——同一套合成器、音频混合与 ffmpeg 编码——因此成片与编辑器里看到的一致。
- `cutline_export {action:"status"}` 报告进度、尝试 ID、运行器进程号与最近一次心跳；`{action:"cancel"}` 请求正在运行的任务停止。

运行器是 Agent 自己拥有的普通 Node 进程，不是 Mini App 的子进程，因此停止 Mini App 不会影响已经被接受的渲染；它也不是脱离管理的常驻守护进程；取消、超时和客户端退出仍受 Agent 任务管理器约束，退出客户端后继续渲染不在支持和实测范围内。同一个任务同时只跑一个：第二次尝试会被拒绝，且不会改动正在运行那次的状态与输出；要重新渲染就重新准备一个任务。

成片先以临时文件写出，只有 `ffprobe` 读通、且 `ffmpeg` 完整解码通过之后，才会标记为完成。写出但没通过检查的文件不会被删除，而是留在任务文件夹的 `provisional` 目录里——它就是渲染器实际产出的东西，还可以查看；没有任何东西会自动清理它。

成片落在任务文件夹里，而这个文件夹不会替你清理：它装着工程快照、媒体与素材库文件副本、渲染运行时和成片本身，因此会占用磁盘空间。状态里会给出成片的绝对路径；把文件复制到你要的位置之后，就可以删掉这个任务文件夹。

运行器需要本机 PATH 中存在 `ffmpeg`、`ffprobe`，以及一份 Chrome 或 Edge 安装；它不会下载浏览器，也不会安装任何软件。由于它不访问网络，本机没有的字体和使用背景移除的片段会被明确拒绝，而不是渲染出与编辑器不同的结果。未知交付预设 ID 也会在准备阶段被拒绝，不会静默回退为 Custom。本版本每个任务只产出一个文件：批量输出是 `fablecut_export` 的功能。

## 导出限制

`fablecut_export` 使用原有编辑器页面中的合成器。外部无头 Chrome 无法访问 Host 认证保护的页面，因此对它不是兜底方案；这类渲染时请保持编辑器打开。长片或高分辨率导出可能受到浏览器资源限制；短片导出成功不代表长片稳定性已经通过。插件未提供独立的通用 FFmpeg 时间线渲染器。

编辑器保留 FableCut 的时间线与效果模型。Skill 说明工具如何使用，不规定创作流程。无论素材由何而来，边界都是导入的媒体文件，时间线格式不变。

## Data & access

- **状态存储：** 工程、媒体副本、版本、分析缓存、代理、素材库和导出文件放在 Host 提供的私有 `context.dataDir` 中，不依赖其物理位置，不写入插件源码目录。导出任务位于同一目录下的 `export-jobs/<任务 ID>/`，其中保存工程快照、其引用到的媒体与素材库文件副本、编辑器和运行时副本、任务状态与成片。该文件夹不会自动删除，会占用自己的磁盘空间，用户在把成片复制出去之后自行清理；未通过检查的文件留在任务的 `provisional` 目录里。
- **读取文件：** 插件自带资源、用户选择或明确传给工具的媒体文件、工程数据和分析产物。接受本地路径的工具会用用户自身的权限读取该绝对路径——**用户能读到的任何文件，而不只是数据目录内的文件**——导入会把读到的内容复制进私有数据目录。导入本地素材会复制文件，不修改原件。准备导出任务只读取已保存的工程以及工程引用到的媒体与素材库文件，不读工程目录之外的任何内容，指向别处的源会被拒绝。
- **写入文件：** 在私有数据目录中写入工程、版本记录、媒体、分析结果、代理和导出文件。工程管理与删除由具体工具或页面操作触发。受管媒体只接受支持的视频、音频、图片和 SVG 扩展名；字体仅限素材库，上传、工程导入和独立导出准备都会拒绝 HTML 和其他非媒体文档。Node 与独立运行器的所有响应统一带 `nosniff`，可由浏览器执行的文档类型统一带 sandbox CSP，为既有文件提供纵深防护。准备好的导出任务只在自己的任务文件夹内写入。
- **网络：** 页面和 MCP 使用 Host 分配的本机监听端口。HTTPS 素材导入访问传入 URL 的主机及允许的重定向目标，本地剪辑不依赖固定外部主机。上游可选的 Google 字体加载访问 `fonts.googleapis.com`、`fonts.gstatic.com`；可选背景移除从 `cdn.jsdelivr.net` 加载 MediaPipe 资源。这些继承功能本轮未实测。独立导出运行器在渲染期间绑定一个 127.0.0.1 上的临时回环端口，不访问其他主机，其提供的页面也不得访问网络。
- **进程：** Node 运行时调用本机 `ffmpeg`、`ffprobe`；不启动额外编辑器服务器或外部无头浏览器。上述程序需另行安装。独立导出运行器是 Agent 在自己的后台任务里启动的另一个 Node 进程，它会启动本机的无头 Chrome 或 Edge，并自行启动与结束 `ffmpeg`、`ffprobe`。
- **Agent 回合：** Mini App 不主动发起 Agent 回合，不声明 `agentAccess`。用户现有聊天中的 Agent 调用 MCP。
- **Host 数据：** 不读取 Host 配置、凭据、私有日志或会话数据库；传输认证由 Host 管理。独立运行器不持有 Host 凭据：它用本次运行生成的密钥保护自己的端口，该密钥不会出现在 URL、命令行参数或日志中。
