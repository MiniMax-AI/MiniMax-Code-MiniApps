      Keyboard shortcuts

      Playback

      SpacePlay / pause (Source or Program — whichever is active)
      J K LShuttle — L plays forward, J in reverse (silent); tap again for 1.5× · 2× · 4×, the other key turns around; K stops
      K+J / K+LHold K and tap to step one frame; hold both to crawl at ¼ speed
      ← →Step 1 frame (⇧ = 1 second)
      ↑ / ↓Jump to previous / next cut (selected clip In then Out; no selection → targeted tracks). Source monitor: In / Out marks
      Home / EndJump to start / end
      0–9 / click timecodeType a time: 01:15:00, packed 1500 (= 15 s), +30 / -1:00 to offset, 12.5 seconds. Click IN / OUT readouts to type those too
      Limit (toolbar)Play stops at OUT; Home / End use IN / OUT

      Source monitor

      Dbl-click bin / clipLoad into the Source monitor
      ,Insert Source In→Out at the timeline playhead (ripples later clips)
      .Replace — overwrite at the playhead, or apply new Source In / Out to a timeline-loaded clip (ripples if the duration changes)

      Editing

      V B R Y UTools: Selection · Ripple edit (drag an edge, the rest follows) · Rolling edit (drag a cut) · Slip (change the source under a clip) · Slide (move a clip, neighbours trim)
      SSplit clip(s) at the playhead (selection, else targeted tracks)
      [ / ]Trim selected in / out to the playhead
      DelDelete selected clip(s), or clear the focused transition
      ⇧+DelRipple delete — remove the selection and close the gap on targeted tracks
      GFind the next shared gap (wraps; respects IN / OUT)
      ⇧+GClose the gap at the playhead (targeted tracks)
      Alt+TAdd a transition at the playhead (in / out by half)
      ⇧+EDisable / enable selected clip(s) — hidden from preview and export
      Ctrl/Cmd+LUnlink / link video and its audio
      Ctrl+Z / Ctrl+⇧+ZUndo / redo (also Ctrl+Y)

      ; / 'Lift / Extract IN→OUT on targeted tracks (Extract closes the gap)
      MAdd / remove a marker at the playhead
      ⇧+M / Alt+⇧+MGo to the next / previous marker
      Marker on rulerDrag to move · click to jump · double-click or right-click to name / colour / delete · Markers lists them all

      Timeline view and tracks
