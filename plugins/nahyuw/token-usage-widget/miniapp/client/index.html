Token 用量

实时查看当前 5 小时与 7 天周期进度、Token 速率与消耗量

用量详情

--

Token 用量设置

选择悬浮窗要展示的指标，并调整刷新频率与外观。

展示指标

勾选的指标会出现在悬浮窗的详情面板中，拖动左侧手柄可调整面板里的先后顺序（也可用 Alt + ↑/↓）。

刷新频率

悬浮窗多久读取一次用量数据。

刷新间隔
账号额度数据本身按分钟级变化，不必过于频繁

悬浮窗

悬浮窗模式下，拖动圆形或顶部手柄即可移动窗口，⌘/Ctrl + 滚轮可即时缩放；设置页顶部的手柄同样可以拖动窗口。

大小
圆形与详情面板同步缩放，共 5 档：最小 / 小 / 中 / 大 / 最大
位置
拖动悬浮窗后的位置会被记住
趋势周期
圆盘里那条趋势曲线的统计窗口

圆盘显示

中心指标、水面高度、外圈进度分别显示哪一项；选速率做外圈时，按当前速度推算 5 小时周期会被烧掉多少。

外观

跟随系统时，优先使用 MiniMax Code 的界面主题。

主题
影响悬浮窗与设置页配色
语言
默认跟随系统语言

数据来源

5 小时与 7 天周期进度来自 MiniMax 账号额度接口；当天与最近 7 天用量来自账号用量接口；速率与趋势取账号实时 Token 累计的差分。
