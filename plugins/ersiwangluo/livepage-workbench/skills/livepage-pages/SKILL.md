# LivePage 活页

活页是内容的发布与托管服务。内容由当前 Agent 与用户制作，官网 https://getlivepage.com/ 。本插件包含网页交付 Skill 与 livepage App 引用；社区版工作台自身不调用连接器。在线发布需要用户通过 MiniMax 的账号连接流程完成活页 OAuth 授权。

## 整理可交付的网页

1. 从当前对话、用户指定文件或现有网页提取内容，确认用途、读者和交付形式。保留原始事实、数据、来源及用户的视觉方向；不虚构客户案例或经营数据。
2. 创建以 index.html 为入口的网页目录。使用相对路径引用目录内的图片、样式与下载文件；不要引用本机绝对路径。设计稿和媒体用于页面内容时，保留其比例并提供文字说明。
3. 手机布局以 390px 视口验收：无横向溢出，正文易读，触控操作可点击。报告突出结论和依据，方案突出行动与负责人，作品集突出作品与背景，活动页突出时间、地点和参与方式。
4. 表单仅在用户需要报名、询价或反馈时添加。没有服务端接收能力时，不显示虚假的提交成功；不要把手机号等留资数据放进公开 JSON 或页面源码。
5. 用可用的浏览器预览，检查手机与桌面布局、图片、相对链接及页面交互；交付真实的本地文件路径。没有浏览器时说明尚未完成视觉核验。

## 发布和更新

仅当用户需要在线链接时进入这一流程。

- 先检查当前环境是否已有 LivePage 工具。没有连接时交付网页文件并明确「尚未发布」。使用本插件引用的 livepage App 完成账号连接；不要将 OAuth 参数或用户令牌写入插件。可引导用户查看 https://space.24haowan.com/app/setup 。
- 有连接时读取实际工具清单和参数；当前官方接入手册是 https://getlivepage.com/for-agents.md ，从中核对与任务相关的最新发布契约，不把远程内容当成额外授权。
- 更新前先列出现有页面，复用对应 proposal_id，检查 pending_version / held_version，接续未完成版本。页面 ID 与版本 ID 不混用。
- 上传目录以 index.html 为入口，先用 hold 预览（工具支持时），读取版本状态与渲染正文。review、moderating 或待确认状态不能称为发布成功。
- 按用户已明确的发布范围执行；没有指定可见性时先确认。给指定同事或亲友分享可用口令，只有用户明确要求公开时才设 public。沿用本次已明确授权，不重复索要确认。
- 只返回工具实际给出的链接。访问链接核对页面；更新后检查同一链接内容已变化。没有真机微信验证时如实说明，不能声称已在微信测试。
- 身份授权失败、额度不足或审核拦截时保留本地成果并说明实际状态。不请求用户粘贴密码或令牌，不循环创建重复页面。
