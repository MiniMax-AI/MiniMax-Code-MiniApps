# 心屿 (`xinyu-daily`)

[English](README.md) | 简体中文

一个玩起来像独立小游戏的每日心情 Mini App。小岛的守岛人是一朵叫小屿的云，你告诉它的事越多，浮岛就长得越热闹。每天可以抽一张灵感卡、贴一张心情贴纸、往罐子里放几颗小确幸，用老虎机解决纠结，再找找自称“岛霸”的坏脾气螃蟹横横藏起来的 20 个秘密。打开“小屿陪伴”后，小屿每天还会给你写一封信、陪你聊天，并把你让它记住的事写进记事本。

心屿自己不发任何网络请求。小屿的来信和聊天默认关闭，只有你打开之后才会运行 Agent，相关记录会发送给你在 MiniMax Code 中使用的模型。界面为中文。

## 能做什么

- **今日灵感卡**：先回答三个轻松的小问题，再翻开一张收集卡。卡上有关键词、能量值、四项小状态、今日色彩、今日数字，以及“适合”和“先放放”的事。你的回答、生日和小屿对你的了解都会影响卡面，偶尔还会抽到闪卡。内容按规则生成，仅供娱乐与自我觉察，不做预测，也不构成建议。
- **心情贴纸与手账**：每天一张贴纸，配有贴纸月历、近 30 天心情曲线、连续打卡奖牌、卡牌收藏册和小确幸墙。
- **纠结粉碎机**：可以亲手拉杆的选择老虎机；答案之书在同一天对同一个问题只给一个答案。
- **自我探索**：12 个“关于你”的问题会让小岛长出小花、树、小屋、灯塔、风车和彩虹，也会改变天气、季节和周末摆件；另有生日花画像和 8 题能量风格小测。
- **小屿的邮筒（可选，使用你的模型）**：第一次点邮筒会收到小屿的邀请信，信里写明它会读哪些内容、这些内容会发到哪里；你同意之前什么都不会发送。打开后，小屿每天根据你最近的心情和备注、小确幸、“关于你”的回答、问过答案之书的问题和最近的聊天写一封信，所以每天的信都不一样，也会跟着你最近说过的事变化。你可以回信、和小屿聊天（每天最多 20 句），说“记住……”让小屿记下一件事，在小屿的记事本里查看或忘掉每一条；贴完心情贴纸，小屿还会回你一句。读过的信收在来信匣里。如果你没有打开，或者模型暂时用不了，小屿会改放一张按规则生成的手写便条。
- **关心提示**：心情备注或聊天里流露出伤害自己的念头时，会弹出一段固定的求助信息，指向全国统一心理援助热线 12356（紧急危险请拨打 110 或 120）。这段文字写在应用里，不由模型生成。
- **探索引导**：开场的“睁开眼睛”、区域横幅、今日旅程清单，还有藏在岛上的 20 个秘密（戳小屿、点月亮、捏云朵、抓流星……）。每找到一个，岛霸横横就得不情愿地交出一枚贝壳，记进秘密图鉴。
- 可开关的合成音效（Web Audio，不含音频文件），天空随时间变化，并支持系统的“减弱动态效果”设置。

## 安装

需要 MiniMax Code 3.1.2 或更高版本：安装包声明了 `agentAccess`，更早的版本无法安装。

把整个目录（包括隐藏的 `.minimax-plugin/`）复制到 MiniMax Code 的插件目录，命名为 `xinyu-daily/`（默认是 `~/.minimax/plugins/xinyu-daily/`，详见根目录 README 的安装说明）。重启 MiniMax Code，然后从右侧面板的 Mini App 入口打开心屿，或者对 Agent 说“打开心屿”。

## Tested environment

- 在 macOS 上的 MiniMax Code 3.1.1-preview.4651 中测试。这是内部预览版，已经包含 3.1.2 的 Mini App Agent API（`context.agent`）。通过宿主的发布流程安装，在右侧面板打开。实测过开场、小屿的自我介绍、“关于你”对话与小岛解锁、今日三问与翻卡、心情贴纸与连续 3 天庆祝、小确幸罐子（放入和摇一摇）、老虎机、答案之书、手账、能量小测、发现秘密与秘密图鉴、白天和夜晚的天空，以及宿主提供 Agent 时设置里会出现陪伴开关。控制台没有报错，也没有失败的请求。
- 小屿陪伴用一个遵循同样 `run` 约定的模拟 Agent 测试过：邀请信（同意、拒绝，以及没有 Agent 时的离线版）、写信和拆信、来信匣、聊天与逐字回复、“记住……”和忘掉便签、心情回应、关闭再打开陪伴、写信失败改放便条和“请小屿重写”、Agent 开始调用工具时取消本轮、超时、每日上限、会话复用与更换，以及关心提示。
- 未完整实测：小屿陪伴还没有接真实模型在真机上跑过完整流程。流星和热气球随机出现；生日蛋糕只在生日当天出现；闪卡全凭运气。音效没有人耳验证。窄屏布局和减弱动态效果是通过阅读 CSS 检查的，没有在真机上验证。

## Data & access

- 文件：只读取自身 `miniapp/client/` 下的文件；只写入一个文件，即宿主提供的 `context.dataDir` 里的 `xinyu-state.json`（先写临时文件再原子替换）。
- 网络：心屿自身不发请求。页面只调用本应用同源的 `/api/` 路由。
- 进程：不启动任何子进程。
- Agent：声明了 `agentAccess: ["session.run"]` 和 `agentConcurrency: 1`。只有在你通过邀请信或设置打开“小屿陪伴”后，才会从 Node 端（`context.agent`）运行 Agent，而且只要求纯文本，共三种：今天的信（外加最多 8 条小屿记下的关于你的短笔记）、聊天回复、对今天心情贴纸的一句话。每次的提示词由应用自己的指令和标注为数据的记录组成：今天的日期、昵称、连续打卡天数、距离生日的天数（不含生日日期）、最近的心情和备注、小确幸、“关于你”的回答、能量风格、今日灵感卡关键词、最近问过答案之书的问题、最近的聊天、记事本，以及上一封信。你忘掉的笔记不会再发送。同一天的请求复用一个会话，这些会话不会出现在你的会话列表里。
- 不用工具、不做审批：如果某一轮开始调用工具、申请权限或者向你提问，应用会直接取消这一轮，从不回复 `allowOnce`，小屿改放手写便条或回一句抱歉。取消是在收到 `tool.started` 事件时发出的，执行很快的只读工具可能在取消前已经执行完。
- 限制：写信 240 秒、聊天回复 120 秒、心情回应 90 秒超时；每天最多聊 20 句、回应 3 次；同一时间只运行一轮。模型的输出会先检查长度和格式、去掉标记，再展示出来。
- 关闭陪伴后不再发起新的请求；还在进行的回复会被丢弃，正在写的信改放一张手写便条。
- `xinyu-state.json` 中保存：昵称、生日、每日心情和备注、抽过的卡片与收藏、小确幸、答案之书记录、小测结果、“关于你”的回答、已发现的秘密、一次性引导标记；陪伴相关的有开关选择、来信（最多 60 封）、最近 3 天的聊天、小屿的笔记、被忘掉的笔记列表和今天的会话 ID。浏览器的 `localStorage` 只保存视图偏好（当前标签页、天空模式、音效开关、开场是否播放过）。
- 重置：设置 → 清空所有数据，会删除所有保存的状态，并取消正在运行的 Agent 请求。
