# 心屿 (`xinyu-daily`)

[English](README.md) | 简体中文

一个玩起来像独立小游戏的每日心情 Mini App。小岛的守岛人是一朵叫小屿的云，你告诉它的事越多，浮岛就长得越热闹。每天可以抽一张灵感卡、贴一张心情贴纸、往罐子里放几颗小确幸，用老虎机解决纠结，再找找自称“岛霸”的坏脾气螃蟹横横藏起来的 19 个秘密。

所有内容都在本机运行：不发网络请求，不运行 Agent。界面为中文。

## 能做什么

- **今日灵感卡**：先回答三个轻松的小问题，再翻开一张收集卡。卡上有关键词、能量值、四项小状态、今日色彩、今日数字，以及“适合”和“先放放”的事。你的回答、生日和小屿对你的了解都会影响卡面，偶尔还会抽到闪卡。内容按规则生成，仅供娱乐与自我觉察，不做预测，也不构成建议。
- **心情贴纸与手账**：每天一张贴纸，配有贴纸月历、近 30 天心情曲线、连续打卡奖牌、卡牌收藏册和小确幸墙。
- **纠结粉碎机**：可以亲手拉杆的选择老虎机；答案之书在同一天对同一个问题只给一个答案。
- **自我探索**：12 个“关于你”的问题会让小岛长出小花、树、小屋、灯塔、风车和彩虹，也会改变天气、季节和周末摆件；另有生日花画像和 8 题能量风格小测。
- **探索引导**：开场的“睁开眼睛”、区域横幅、今日旅程清单，还有藏在岛上的 19 个秘密（戳小屿、点月亮、捏云朵、抓流星……）。每找到一个，岛霸横横就得不情愿地交出一枚贝壳，记进秘密图鉴。
- 可开关的合成音效（Web Audio，不含音频文件），天空随时间变化，并支持系统的“减弱动态效果”设置。

## 安装

把整个目录（包括隐藏的 `.minimax-plugin/`）复制到 MiniMax Code 的插件目录，命名为 `xinyu-daily/`（默认是 `~/.minimax/plugins/xinyu-daily/`，详见根目录 README 的安装说明）。重启 MiniMax Code，然后从右侧面板的 Mini App 入口打开心屿，或者对 Agent 说“打开心屿”。

## Tested environment

- 在 macOS 上的 MiniMax Code 3.1.1-preview.4651 中测试：通过宿主的发布流程安装，在右侧面板打开。实测过开场、小屿的自我介绍、“关于你”对话与小岛解锁、今日三问与翻卡、心情贴纸与连续 3 天庆祝、小确幸罐子（放入和摇一摇）、老虎机、答案之书、手账、能量小测、发现秘密与秘密图鉴、白天和夜晚的天空。控制台没有报错，也没有失败的请求。
- 未完整实测：流星和热气球随机出现；生日蛋糕只在生日当天出现；闪卡全凭运气。音效没有人耳验证。

## Data & access

- 文件：只读取自身 `miniapp/client/` 下的文件；只写入一个文件，即宿主提供的 `context.dataDir` 里的 `xinyu-state.json`（先写临时文件再原子替换）。
- 网络：无。页面只调用本应用同源的 `/api/` 路由。
- 进程：不启动任何子进程。
- Agent：不运行 Agent，没有声明 `agentAccess`。
- `xinyu-state.json` 中保存：昵称、生日、每日心情和备注、抽过的卡片与收藏、小确幸、答案之书记录、小测结果、“关于你”的回答、已发现的秘密、一次性引导标记。浏览器的 `localStorage` 只保存视图偏好（当前标签页、天空模式、音效开关）。
- 重置：设置 → 清空所有数据。
