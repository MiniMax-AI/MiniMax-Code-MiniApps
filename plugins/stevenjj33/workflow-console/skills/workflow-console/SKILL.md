# 动态工作流控制台

`workflow-console` 是一个 Mini App：把 MiniMax Code 的动态工作流（多 Agent 编排）放进一个页面里——
运行列表、实时事件流、按阶段与依赖画出的流程图、每个节点的输出、审核与控制、模板、报告导出。

它**自带** Workflow Studio 引擎，不需要另外安装 `mcode-dynamic-workflows` 插件。

用 Mini App 工具打开插件 `workflow-console`（页面路由 `/dashboard`）。界面是中文的。

## 第一件事：确认项目目录，不要猜

控制台**不会**替用户挑工作目录。没有项目目录，引擎根本不启动，页面会显示「还没有选择项目目录」。

解析顺序是服务端固定的，别自己另发明一套：

1. 宿主声明的当前项目——`MCODE_WORKSPACE` / `MCODE_PROJECT_DIR` / `PROJECT_DIR` / `WORKSPACE` 环境变量。
2. 用户在页面顶部「工作目录」栏里填的绝对路径（记在 `context.dataDir` 的 `workspace.json`）。
3. 都没有 → 引擎不启动，页面要一个绝对路径。

要做的：

- 页面报「还没有选择项目目录」→ **问用户**要哪个项目的绝对路径，不要从当前会话随手推断一个。
- **家目录和宿主投放目录一律不行**，服务端直接拒绝（400）。理由很实在：一次运行就能改写整个家目录。
- 换目录会让引擎重启；属于旧目录的运行将无法开始或恢复（上游要求运行与引擎同工作区）。所以别在运行进行中改目录。

## 运行的生命周期

```
待审核(pending_review) ──「开始执行」──> 运行中 ──> 完成 / 失败 / 已取消
```

- 草稿进来就是**待审核**，不会自己跑。
- 「开始执行」＝审核＋启动，会先弹确认框，然后调度真实 Agent。
- 演示草稿（demo 执行器）不调用模型，只演流程。

**用户点下去之前，你要替他核对**（这一步之后没法收回）：

- 拓扑对不对：阶段划分、依赖关系、有没有孤立节点。
- 每个节点要读什么、写什么——引擎在这个目录里跑，`mcode` CLI 会在里面读写文件。
- 执行器是 `demo` 还是 `mcode`。

**除非用户明确说了「直接开始」，否则不要替他点「开始执行」。** 这一步会真的动他的项目目录。

## 控制运行

运行中可暂停、取消、恢复（恢复前要确认之前那个 Agent 确实停了）。

- 报「审核版本已更新，请刷新后再开始执行」＝409：审核对象变了，刷新页面重新核对后再审。
- 待审核的草稿可以直接取消（上游支持直接取消草稿）。

## 模板

- 把一次运行存成模板，之后复用。
- **复用模板＝新建一份待审核草稿，不是直接执行。** 别把复用说成「已经跑起来了」。

## 报告

运行结束可导出 Markdown / HTML 报告。给用户结论时别把原始事件日志整段贴回去——
挑关键节点输出和最终结论。

## 先 demo，后 mcode

| | demo | mcode |
| --- | --- | --- |
| 调模型 | 否 | 是，调度真实 Agent |
| 前提 | 无 | 机器上有 `mcode` CLI 且已登录 |
| 用途 | 验拓扑、验流程 | 真正干活 |

页面上 `mcodeAvailable: true` 只说明 `mcode` 可执行文件存在，**不代表它登录了或还有额度**。
真实执行失败时先查登录和额度，别直接归因给工作流本身。

CLI 找不到时，控制台会在横幅上写明并**拒绝启动真实执行**——这时候别反复重试，让用户先装好并登录，
或改用 demo 执行器。引擎查找 CLI 的顺序：`PATH` 里的 `mcode` → 官方用户安装位置
（macOS/Linux 是 `~/.minimax-code/bin/mcode`，Windows 是 `~/.minimax-code/mcode.cmd`）→
`$MCODE_INSTALL_DIR` 指定的目录。

## 数据与边界

- 引擎只监听 `127.0.0.1`，控制台只代理到它：不连外网，也不连别的本地服务。
- 状态文件全在 `context.dataDir`：`workspace.json`、`hidden-runs.json`、`engine/`。
- 引擎在项目目录里工作，真实执行会读写那个目录。
- 隐藏某个运行只是本地隐藏，不是删除；运行记录还在引擎数据库里，可以恢复。

## 不要做的事

- 不要替用户猜工作目录。
- 不要把 `demo` 的结果说成真实模型跑出来的。
- 不要在用户没确认时替他批准并开始执行。
- 不要把「复用模板」说成「已执行」。
