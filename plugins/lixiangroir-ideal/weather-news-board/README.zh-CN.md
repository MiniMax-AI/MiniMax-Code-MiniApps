# 天气 · 新闻看板

一个独立运行的 Mini App，把实时天气、A 股与国际品种行情、六个可切换的新闻栏目放在同一页看板上。

- **实时天气** —— 当前温度、天气状况、体感温度、湿度、风速，以及带降水概率的三天预报。城市可以直接
  输入中文（例如 `南京`），**切换** 按钮会在同名城市之间轮换。
- **自选股** —— 自建的自选清单，支持 A 股代码与黄金、白银、原油、比特币期货、上海金 9999 等国际
  品种。行情按自己的间隔自动刷新，与天气、新闻的刷新开关互相独立；卡片底部给出涨、跌、平的条目
  计数。
- **新闻** —— 六个栏目：要闻、时政、科技、财经、热榜（今日头条）、知乎日报。顶栏的刷新按钮会立刻重取当前
  栏目，跳过服务端 60 秒的缓存。

贵金属一律以**人民币 / 克**显示。原始的美元 / 盎司报价和换算所用汇率放在该行的悬停提示里，
方便和来源数值对照。

每张子看板的标题栏里都有一个专注按钮：点它会把另外两张收起来，让这一张占满看板；再点一次
同一个按钮，或者点顶栏的「退出专注」，就回到完整看板。

调整某张卡片的尺寸时，同一行的每张卡都会显示自己还能取的宽度范围——兄弟卡已经让到底时一眼
就能看见；提示条上也会带上同样的区间。

缩放手柄本身是一个真正的按钮：手柄获得焦点后，方向键可以调整这张卡的宽和高（按住 Shift 步长
更大），Home 让这张卡恢复自适应尺寸。

整页依据**容器宽度**而不是窗口宽度重排，因此无论开在窄侧边栏还是宽屏下，观感保持一致。每张子看板的
右下角各有一个缩放手柄：**天气、自选股、新闻**各自独立调整宽与高，天气卡可以又窄又矮，自选股卡仍
然保持宽屏，每个尺寸分开记住。拖动时实时显示当前尺寸；手动指定高度后，内容在卡片内部滚动；单击手柄
只复位这一张卡片，顶栏的「重置尺寸」一键还原全部。天气卡与自选股卡并排且都没有手动指定尺寸时，两者
高度保持一致，多出来的空间由逐时预报（未来若干个三小时档位）逐条填满；三栏布局按同一条规则显式对齐，
两张卡片的高度都取两者中较高的一档。从本地存储恢复的尺寸会按当前容器夹紧，因此在宽屏下存下的尺寸不会
把窄屏里的卡片压扁。同一行的卡片宽度之和也不会超出容器：宽度放不下时按比例收回，同样宽的几张卡会
一起等比收窄，而不是永远先收行里的第一张；拖动某张卡时，兄弟卡片先让出空间，而不是把看板撑出边界、
让右侧被裁掉。拖动时提示上的尺寸就是实际生效的尺寸。

看板在自己的服务还没起来时也能正常工作。宿主会在页面不可见时停掉 Mini App 进程，因此页面重新
回到前台时，服务可能已经不在了。请求连不上服务（完全没有响应，或响应不是 JSON）会按 0.4 秒、
0.8 秒、1.6 秒、3.2 秒、6.4 秒、10 秒的递增间隔重试，顶栏同时显示距下一次尝试还剩多久。请求
确实到达了服务、但因为上游数据源失败而报错时不会重试——上游出问题不会被误看成服务出问题。重试
用尽后，顶栏改为提示服务尚未就绪，下一次自动刷新会把看板重新接上。增删自选股同样按这套机制
重试，由于这两个操作在服务端是幂等的，重试不会写重。

宽度上的算术与 DOM 是分开的：客户端把纯函数放在 `<script id="wnb-layout">` 这一段里，
`tests/layout.test.mjs` 把这一段原样取出来，用 Node 自带的测试运行器跑一遍。列数断点、同一行的
宽度上限、按比例收回、夹紧都在用例里覆盖，改布局规则不必先打开应用就能验证：

```sh
node --test "plugins/lixiangroir-ideal/weather-news-board/tests/*.test.mjs"
```

跑的正是页面自己执行的那一段代码，所以测试与应用不会走偏。

## 安装与打开

1. 在 MiniMax Code 中安装本插件。
2. 从插件入口打开「天气 · 新闻看板」Mini App，或直接让 Agent 帮你打开。

本应用无需任何配置、账号或构建步骤，页面上的一切都是运行时实时抓取的。

自选股里可以填六位 A 股代码（`600519`）、带市场前缀的代码（`sh600519`、`sz000001`、`bj430047`），
或者支持的品种名称（`黄金`、`伦敦金`、`黄金9999`、`白银`、`原油`、`比特币`）。代码在服务端按固定
白名单校验，其他输入一律拒绝。

## Data & access

- **读取的文件** —— 安装包内的 `miniapp/client/index.html`，由分配到的回环端口提供。
- **写入的文件** —— 宿主注入的 `context.dataDir` 下的 `watchlist.json`，采用「先写临时文件再改名」
  的原子写法。该目录位置由宿主决定，插件不感知。
- **浏览器存储** —— `localStorage` 只保存视图偏好：当前新闻栏目、两个刷新间隔、当前城市、浅色 /
  深色主题，以及逐张卡片拖动得到的宽与高。不存放任何行情或文章数据。
- **网络主机**（全部为 Node 侧发起的只读 HTTPS 出站请求）：`wttr.in`、
  `geocoding-api.open-meteo.com`、`www.chinanews.com.cn`、`www.ithome.com`、`sspai.com`、
  `www.yicai.com`、`www.toutiao.com`、`top.baidu.com`、`news-at.zhihu.com`、
  `push2.eastmoney.com`、`hq.sinajs.cn`、`qt.gtimg.cn`。
- **启动的子进程** —— 无。上游请求全部由 Node 运行时的 `fetch` 发出。
- **Agent 回合** —— 无。本应用从不发起 Agent 运行。
- **读取的会话** —— 无。
- **调用的工具** —— 无。
- **麦克风、摄像头、通知** —— 均未使用。
- **宿主导航读取** —— 未使用。
- **声明的访问权限** —— 除标准 Mini App 运行时外没有任何声明：未声明 `hostConnectorAccess` 提供方、
  `agentAccess`、`toolAccess`、`deviceAccess` 与 `hostAccess`。
