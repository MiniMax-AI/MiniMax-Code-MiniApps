# 天气 · 新闻看板

一个独立运行的 Mini App，把实时天气、A 股与国际品种行情、六个可切换的新闻栏目放在同一页看板上。

- **实时天气** —— 当前温度、天气状况、体感温度、湿度、风速，以及带降水概率的三天预报。城市可以直接
  输入中文（例如 `南京`），**切换** 按钮会在同名城市之间轮换。
- **自选股** —— 自建的自选清单，支持 A 股代码与黄金、白银、原油、比特币期货、上海金 9999 等国际
  品种。行情按自己的间隔自动刷新，与天气、新闻的刷新开关互相独立。列表按应用实际拿到的宽度自动
  排成多列，条目再多也不会被挤出可视区域。
- **新闻** —— 六个栏目：要闻、时政、科技、财经、热榜（今日头条）、知乎日报。

整页依据**容器宽度**而不是窗口宽度重排，因此无论开在窄侧边栏还是宽屏下，观感保持一致。

贵金属一律以**人民币 / 克**显示。原始的美元 / 盎司报价和换算所用汇率放在该行的悬停提示里，
方便和来源数值对照。

## 安装与打开

1. 在 MiniMax Code 中安装本插件。
2. 从插件入口打开「天气 · 新闻看板」Mini App，或直接让 Agent 帮你打开。

本应用无需任何配置、账号或构建步骤，页面上的一切都是运行时实时抓取的。

自选股里可以填六位 A 股代码（`600519`）、带市场前缀的代码（`sh600519`、`sz000001`、`bj430047`），
或者支持的品种名称（`黄金`、`伦敦金`、`黄金9999`、`白银`、`原油`、`比特币`）。代码在服务端按固定
白名单校验，其他输入一律拒绝。

## Tested environment

- MiniMax Code **3.1.19**，**Windows 11**（Windows 10.0.26200，x64），Node.js 24.16.0。
- 客户端验收覆盖：发布并打开 Mini App，确认页面非空白、地标、标题、标签页与控件均可访问；用
  420 px、640 px、1100 px、1440 px 四种容器宽度驱动布局，确认看板依次由一栏重排到两栏、三栏，
  全部自选股条目都留在卡片内、任何宽度都不出现横向溢出、自选股按可用宽度排成尽可能多的列；
  检查深色主题；增删自选股；逐个切换新闻栏目；确认一个自动刷新周期后行情时间戳与价格确实跳动；
  刷新页面后自选股、当前栏目与主题均保持。控制台 0 error / 0 warn，网络无失败请求。
- 未验证：百度热榜兜底与新浪 / 腾讯行情备源只针对其接口单独做过直连验证，因为主源一直可用，
  运行时并未真正走到兜底分支。
- 本包未声明 `agentAccess`、`toolAccess`、`deviceAccess`、`hostAccess` 与 `surface.window`，
  因此除基础 Mini App 运行时外没有更高的客户端版本要求。

## Data & access

- **读取的文件** —— 安装包内的 `miniapp/client/index.html`，由分配到的回环端口提供。
- **写入的文件** —— 宿主注入的 `context.dataDir` 下的 `watchlist.json`，采用「先写临时文件再改名」
  的原子写法。该目录位置由宿主决定，插件不感知。
- **浏览器存储** —— `localStorage` 只保存视图偏好：当前新闻栏目、两个刷新间隔、当前城市、浅色 /
  深色主题。不存放任何行情或文章数据。
- **网络主机**（全部为 Node 侧发起的只读 HTTPS 出站请求）：`wttr.in`、
  `geocoding-api.open-meteo.com`、`www.chinanews.com.cn`、`www.ithome.com`、`sspai.com`、
  `www.yicai.com`、`www.toutiao.com`、`top.baidu.com`、`news-at.zhihu.com`、
  `push2.eastmoney.com`、`hq.sinajs.cn`、`qt.gtimg.cn`。
- **启动的子进程** —— 无。上游请求全部由 Node 运行时的 `fetch` 发出。
- **Agent 回合** —— 无。本应用从不发起 Agent 运行。
- **读取的会话** —— 无。
- **调用的工具** —— 无。
- **麦克风、摄像头、通知** —— 均未使用。
- **宿主导航读取** —— 未使用。
- **声明的访问权限** —— 除标准 Mini App 运行时外没有任何声明：未声明 `hostConnectorAccess` 提供方、
  `agentAccess`、`toolAccess`、`deviceAccess` 与 `hostAccess`。
