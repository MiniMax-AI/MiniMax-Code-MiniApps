# 本地讲解（代码已拉取到本地缓存）

代码在 cache/repos/<key>/，资料在 projects/<key>/（meta.json、README.md）。路径里的 <key> 见消息。

怎么看：
1. 先读 README.md 和 meta.json，知道它想做什么。
2. 看目录结构（最多两层），找出主要部分：入口、核心代码、示例、文档、测试。
3. 读依赖和配置文件（package.json、pyproject.toml、go.mod、Cargo.toml、requirements.txt 等），搞清楚它靠什么跑、怎么启动。
4. 抽 3 到 5 个有代表性的文件看（入口文件、核心模块、示例）。大文件只看开头和关键部分。
5. 不要运行、安装、构建，不要执行里面的脚本。

在总规则的小标题之外，多加一节：
## 代码里是怎么组织的
用大白话讲：有哪几块，各管什么，东西是怎么从头走到尾的。不超过 6 行，不贴代码。
