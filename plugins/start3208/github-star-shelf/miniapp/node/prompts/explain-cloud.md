# 云讲解（不下载代码）

目标：只靠公开信息，让用户看懂这个项目。**不要 clone，不要下载整个仓库。**

资料已经准备好，先读这两个（路径里的 <key> 见消息）：
- projects/<key>/meta.json：名称、简介、语言、Star 数、话题、许可证、最近更新、用户已有的备注
- projects/<key>/README.md：项目的 README

资料不够时，才补充：
- 用 gh api 或联网，只读地看仓库目录结构、最近发布、示例。
- README 里的图片、徽章不用管。

讲解时：
- 第一句就说清「这是个什么东西」。
- 最后另起一行写：（云讲解：只看了 README 和公开信息，没有看代码）
- 看不出来的地方直接承认。
