The Quota Bottle implementation in this package is an independent implementation
written for this community repository. It speaks the public MiniMax Token Plan
and device-authorization HTTP endpoints and follows the published Mini App
contract in this repository. It does not copy or redistribute source files from
the `MiniMax-AI/cli` repository.

protocol and API identifiers, not a license grant over this package's source.

package implements the behaviour from that description rather than embedding
upstream source.
