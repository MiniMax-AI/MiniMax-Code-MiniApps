# MiniMax Photo 用户手册

## 开始创作

欢迎页可打开图片、新建画布或试用示例作品。商品、肖像和海报示例均可继续编辑。

## 保存与恢复

“更多 → 保存工程”保留图层，下载的 .pcraft 文件可以再次打开。“导出 PNG”保存合并图片。应用每隔几秒检查当前作品的变化并在本机备份，可从“更多 → 恢复作品”找回。刚完成的修改可能还未备份；关闭前请保存重要作品。

## 与 AI 协作

打开右下角的 AI 助手，直接输入需求并发送。AI 会按需要读取画面、编辑图层或生成图片。标题栏可以拖动，减号收起面板。窄窗口下显示在底部，不会占用固定侧栏。

## 在 MiniMax Code 聊天中使用

也可以新建聊天，选择模型，输入 `@` 选择 MiniMax Photo，再附上参考图片。例如：“照这张图画简单的铅笔素描，尽量像原图，逐笔画给我看。”参考图应作为图片附件添加，无需把本机路径写进请求。

Agent 会自行打开 Mini App、选择工具、检查画面并做必要修正。一条请求可以包含多次工具调用，不代表一次调用就画完。复杂任务可能需要数分钟；相似度和细节仍需要检查。

## 让 AI 打开和检查工程

可以说：“打开这份 PSD，检查尺寸和图层。”把文件作为附件提供；如果文件由 AI 刚刚导出，也可以说“重新打开刚才的 PSD”。AI 使用文件导入工具在新文档中打开，保留当前作品。

目前 AI 文件导入支持 PNG、JPEG、WebP、PSD 和 .pcraft，单个文件最多 32 MB。更大的文件可尝试编辑器“文件 → 打开”，但仍受设备内存限制。PSD 的复杂效果和特殊字体可能有差异，打开后检查画面；保存重要工程时同时保留原文件。

## 查看图片与进度

生成的图片显示在“AI 返回的图片”，点击“打开图片”会打开新作品，原作品保留。发送过程中可以停止；需要许可或补充信息时，在面板里操作。读取结果失败时可点击重试。

## 继续上次对话

草稿和最近回复会自动保存在本机。重新打开后继续使用原会话。标题栏的加号可新建对话，保留尚未发送的草稿。若上次任务结果不确定，请先“查看完整会话”，不要重复发送。请不要同时在两个窗口修改同一份 AI 会话。

## 语言与兼容性

“更多 → 语言”支持简体中文、繁体中文、English 和日本語。旧 .retouch.json 文件从“打开旧版工程”打开。复杂 PSD、特殊字体和部分滤镜可能与桌面软件有差异；重要作品请检查导出结果。

自动备份保存当前活动作品，切换后才会检查其他作品；不代替工程文件备份。AI 生图和改图使用 MiniMax Code 当前可用的模型与权限。

## 查看 AI 编辑过程

执行时显示处理提示。画笔、铅笔和混色画笔完成后，会短暂回放轨迹并标出路径范围；连续批量笔画最多显示最后 8 条。混合操作的批次仅高亮画布，避免变换后轨迹对不齐。

“更多 → 显示 AI 操作轨迹”可以关闭，设置会保留。拖动画布、缩放、键盘操作或下一次编辑会立即收起提示。系统开启减少动态效果时显示静态轨迹。回放不写入作品、不增加撤销步骤；现有撤销仍撤销真实编辑。AI 停止按钮不会强行中断已提交到编辑器的同步命令。

## 录制绘画过程

在“更多”中选择“录制绘画过程”，顶部出现“停止录制”。结束后，在“更多”中选择“保存录制视频”，得到 WebM 文件。录制范围是编辑器自己的画布（含编辑器工具栏），不包含 MiniMax Code 的聊天和模型回复，也不会拍到桌面或其他窗口，不需要屏幕录制权限。要展示从附图、发送请求到最终回复的整个流程，请在发送前使用外部录屏工具录制 MiniMax Code 窗口；应用内录制无法补回聊天过程。

保存窗口取消后可以再次保存；保存完再“清除录制缓存”即可开始下一次录制。未保存视频只在当前页面内存中，刷新或关闭会丢失。达到 60 分钟或 256 MiB 时自动结束，仍可保存。后台窗口可能被浏览器降帧。录制保留真实画面变化，不会把一次提交的整幅图自动变成逐笔动画；让 AI 展示过程时仍需使用逐笔绘制。
