## 社区静态检查提示

`ENTRY_STDOUT` 命中了打包的 QuickJS/Emscripten 库中的默认日志代码。该文件只在 worker thread 中运行；创建线程时启用独立 stdout/stderr 并消费其流，不会写入宿主入口进程的标准输出。结构化错误仍经 worker 消息返回。此提示在 PR 中保留说明，不修改检查器或隐藏第三方代码。
