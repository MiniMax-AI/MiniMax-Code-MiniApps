# MiniMax Video

[English](README.md)

基于 [OpenChatCut](https://github.com/0xsline/OpenChatCut) 的 MiniMax Code 视频编辑应用。支持多轨剪辑、字幕、浮动 AI 助手和导出；AI 修改先预览，再由你应用。

## 安装与上手

需要 MiniMax Code 3.1.2 或更新版本。把本目录连同隐藏的 `.minimax-plugin` 复制到 `<dataDir>/plugins/openchatcut/`，重启客户端后让 Agent 打开 MiniMax Video。插件 ID 保留为 `openchatcut`，便于继续使用旧工程；不要同时安装另一份。

首次启动选择中国大陆或海外下载源，自动安装经过摘要校验的媒体依赖，无需手动安装 Node、npm 或 FFmpeg。后续可在“设置与关于”切换来源。已有缓存可复用，未下载的资源需要联网。

1. 点击“打开示例”，新建包含三段画面、字幕和原创配乐的 12 秒工程，不覆盖旧工程。
2. 播放示例，或上传自己的素材。
3. 打开“剪辑助手”，输入“把最后一句字幕改成你好，MiniMax Video，其他内容不变，提交修改预览”。
4. 点击“预览结果”，确认后应用。
5. 从右上角导出 MP4；只需音频时选择“音轨 MP3”。

生成图片、视频或语音需要先在 MiniMax Code 配好相应工具。示例要求：“生成一张暖橙色图片，加在视频最后作为三秒结尾，提交预览”。遇到导入确认时先核对来源和名称；确认后如果助手已结束回复，再发“继续原操作，复用已有文件，不重新生成”。生成可能收费或带水印。素材导入不等于时间线修改已应用。

## 实测与限制

2026-10-19 在 macOS Apple Silicon、MiniMax Code 3.1.3-preview.4675 原生窗口实测：示例创建和播放、工程保留、助手记录恢复、下载源切换、MP3 导出，以及 AI 真实生图、导入、抽帧、预览、应用、MP4 导出。导出的 12 秒 MP3 非静音；15 秒 720p/30fps MP4 完整解码，结尾可见生成图片。

Windows、全部高级特效和导出格式、每种生成服务未逐一验收。平台清单支持范围和数据访问说明见 [English README](README.md#data--access)。首次离线安装不可用；本地聊天显示记录可能因清缓存或访问地址变化而丢失，恢复时先检查完整对话，不自动重复生成。

## 数据、权限和许可证

工程、素材和依赖缓存保存在宿主提供的应用数据目录。导入读取你选择的文件，导出写入你选择的位置；系统字体读取本机已安装字体。会按需启动 FFmpeg、FFprobe、Remotion 和 Chromium。网络来源、生成服务与 Agent 权限详见 [Data & access](README.md#data--access)。本应用运行的宿主 Agent 可以使用文件、Shell 和 MCP 能力，确认请求由用户处理。

更新时先关闭应用并退出客户端，再替换完整插件目录，保留独立的工程数据。不要为清缓存删除整个数据目录。

本应用遵循 AGPL-3.0-or-later，保留 OpenChatCut 署名与第三方许可。[源码与重建说明](source/README.md)和[许可证](LICENSE)随仓库提供。Remotion 等依赖另有自己的许可条款。

在 MiniMax Code 内导出时，先点“选择…”指定保存文件，再开始导出。默认浏览器下载方式依赖宿主的下载处理。
