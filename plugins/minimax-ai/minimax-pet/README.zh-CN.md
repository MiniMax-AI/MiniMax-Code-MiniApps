# MiniMax Pet

[English](README.md) | 简体中文

作者：**MiniMax**。围绕主窗口可见会话提供轻量陪伴、任务状态与通知，界面提供“外观／任务／设置”三个页签。

## 使用

将仓库 `plugins/minimax-ai/minimax-pet/` 完整复制到 `<dataDir>/plugins/minimax-pet/`，包括隐藏的 `.minimax-plugin`；默认 `<dataDir>` 为 `~/.minimax`，自定义数据目录时采用实际配置。不要复制外层作者目录。重启 MiniMax Code、确认插件启用后，从 MiniApp 列表打开“MiniMax Pet”，或对 Agent 说“打开 MiniMax Pet”。点击“放到桌面”显示透明桌宠窗口。

外观页支持选择、导入预览和删除已导入宠物；任务页显示提醒、全部可见任务和按 Markdown 渲染的最近回复；设置页提供大小、提醒管理和重连。桌面通知最多预览五行，点击后可滚动读完整内容，桌宠保持可见。观察到 ask 时显示“需要你回答”。

在 MiniMax Code 3.1.11 及以上版本，面板和桌面上的任务详情都有“打开对话”按钮，任务需要回答时显示为“去回答”；点一下会把 MiniMax Code 主窗口切到这个对话。面板和桌面卡片的明暗也跟随 MiniMax Code 的主题。旧版本客户端不显示该按钮，明暗跟随系统设置。

**0.5.10** 新增可选内置宠物 **麦芽糖**，是一位珊瑚粉触手长发的 Q 版全身章鱼娘。在“外观 → 选择宠物”中选择她，预览下方会显示她的自述；薄荷色机器人仍为默认宠物。麦芽糖采用现有 v2 图集，包含九种动作和十六个视线方向，沿用六帧、6.6 秒一轮的慢速待机，不新增权限或改变播放器。图集已通过校验，并在 Linux 的本地插件界面完成导入和选择；这不代表正式客户端的 bundled 安装或透明桌面窗口已验收。AI 创作流程和贡献者许可见[素材说明](ARTWORK.md)。

**0.5.11** 新增可选内置宠物 **MMX 章鱼娘**，是一位橙发、白背心、棕格纹短裙的 Q 版全身章鱼娘。在“外观 → 选择宠物”中选择她即可；薄荷色机器人仍为默认宠物。她采用 v1 图集，包含九种动作，不含十六个视线方向，因此鼠标跟随对她不生效；沿用六帧、6.6 秒一轮的慢速待机，不新增权限或改变播放器。图集已通过校验。创作流程和贡献者许可见[素材说明](ARTWORK.md)。

**0.8.1** 修复桌面卡片：标题单行截断，只有回复区滚动，底部操作固定在卡片内；长标题或长回复不再把「返回任务 / 打开对话」顶出卡片。展开卡片时窗口同步变高，回复不会被压成一行。

**0.8.0** 按 MiniMax Code 的设计语言对齐面板：24px 页边距与区块间距、14px/22px 正文与 12px/18px 辅助文字、控件最小高度 32px、卡片 12px 与控件 8px 圆角、桌面浮层 0.5px 描边，并补齐按下与焦点状态。桌面宠物保持 280px 布局，沿用同一套 token。

**0.7.0** 把任务最近回复按 Markdown 渲染：标题、强调、列表、任务清单、代码块、表格、引用和链接；回复里的原始 HTML 只作为文本显示，图片显示为文字标签而不发起网络请求。通知卡片和提醒预览仍为纯文本。解析使用 `npm run build:markdown` 打包的 unified + remark-parse + remark-gfm（MIT）；页面不会把模型输出拼成 HTML 字符串。

**0.6.0** 删除了菜单和外观页里的“打招呼”“跳一下”，删除了原属聊天草稿及其语音输入，不再申请麦克风权限；新增“打开对话／去回答”和主题跟随。支持基线仍为 MiniMax Code 3.1.6：两项新功能都先检测客户端能力，不需要新增权限。

旧的本地原型使用不同插件 ID。`minimax-pet` 会有独立的 Host 数据目录，安装本包不会自动搬迁旧插件的宠物和偏好；需要的素材先导出，保留旧安装和数据。

## 环境与兼容

本包支持 MiniMax Code **3.1.6 及以上版本**。2026-10-26 核对的[中国大陆](https://filecdn.minimax.chat/public/minimax-agent-prod/release/latest-mac.yml)与 [Global](https://file.cdn.minimax.io/public/minimax-agent-prod/release/latest-mac.yml) 正式更新清单均为 3.1.6，并已核对同版本发行实现包含所需接口。这确认了正式发布的 API 基线，不代表本插件已在该正式客户端完成 GUI 验收。

任务监控使用 `agent.sessions/session/observe/cancel`，需要 `session.read` 授权。保留运行时能力和权限检查，缺少接口或关闭授权时显示不可用。“打开对话／去回答”使用 `host.navigation.open`，主题跟随使用 `host.ui.subscribe`，两者都从 MiniMax Code **3.1.11** 起提供；2026-11-10 已确认 3.1.11 的 macOS 与 Windows 安装包在两个正式 CDN 上均可下载。两项调用已对照 MiniMax Code 源码核对：打开插件已持有的会话不需要 `hostAccess` 或其他授权，必须在点击中发起，并会把主窗口带到前台。

更早的 UI 版本已在 macOS 开发版验收三页签、窄宽布局、真实任务与 ask、导入删除和桌面切换；0.6.0 运行 Node／DOM 测试（含模拟 Host 下的打开对话与主题路径）、隔离 HTTP smoke，并在 Host 之外用浏览器检查了面板布局。默认图集通过 PNG 解码、动画帧覆盖与确定性重建检查；独立的章鱼图标通过 PNG 解码和视觉检查。2026-10-26，已用 macOS 开发版中的真实 Agent 调用随包 Skill，完成自定义 v2 宠物的生成、校验、预览和导入，并检查九种动作预览与鼠标上／右／下／左四向注视。0.6.0 尚未在真实的 MiniMax Code 3.1.11+ 窗口（面板或桌面宠物）中验收打开对话和主题跟随，也未验收 Windows GUI、正式客户端安装或 3.1.6 正式版 GUI；合成数据测试不能证明这些路径。

## 数据与能力边界

只申请 `session.read`，读取 Host 对本插件可见的用户会话状态和所选会话最新回复，不直接读取 Host 数据库、日志、配置或凭据。状态和提醒只在页面内存中，关闭或静音不修改 Host 的任务或未读事实。

全局观察聚合可见任务，初始快照至多 50 条；本连接已观察到、Host 仍确认可见的任务会继续保留。另三个详细观察名额监听活跃会话的 ask，任务结束或移除后取消，等待旧订阅真正结束再补位。详细观察是 tail-only，不能补回订阅前或断线期间的问卷；超过三个活跃任务时，只覆盖其中三个的详细事件。没有观察到 ask 不等于没有待答问卷。

偏好和用户导入素材写入独立的 `context.dataDir`；导入替换有中断恢复，删除限于本插件数据。不创建独立聊天、不写入聊天输入框、不逐会话点评、不自动调用模型、不发送或停止用户会话、不代答问卷。

回复由随包 vendor 的解析器转为 Markdown 结构，再在页面里用 DOM 节点重建：原始 HTML 只按文本显示，不会插入页面或执行；链接只显示地址不打开；图片不请求，只显示文字标签。

只有在你点击“打开对话”或“去回答”时，页面才调用 `host.navigation.open({ id: 'session', sessionId, source: 'local' })`，目标是已通过 `session.read` 列出的会话。未声明 `hostAccess`，不读取你在 MiniMax Code 里停留的页面。`host.ui.subscribe` 只用来读取并应用主题，返回的语言不使用，无需授权。不使用也不声明麦克风、摄像头或系统通知。插件本身没有硬编码的外部服务地址，只使用分配的 loopback 源，不启动额外子进程或 shell。

## Agent Skill

随包的 `minimax-pet` Skill 既能打开插件，也能指导当前 Agent 制作、校验和导入自定义宠物。格式文档列出 v1/v2 的精确尺寸、逐帧布局、透明背景、视线方向和 `pet.json`，并附带无外部依赖的 PNG 校验脚本。生成文件先放在用户工作区，再通过界面确认导入；MiniApp 不自行启动模型。

## 开发与许可

保留源码／分发双目录，构建与完整字节对比步骤见 [PROVENANCE.md](PROVENANCE.md)。原创代码、文档、两只内置宠物和图标均按 [MIT](LICENSE) 开源，作者为 MiniMax。默认的薄荷色机器人图集由可编辑的几何绘图代码生成；第二只内置宠物“MiniMax Code 章鱼娘”（`minimax-tako`）粉发、戴眼镜、酒红触手，由 MiniMax 图像生成根据用户提供的参考图绘制后拼成 v2 图集，无法用命令重新生成；紫色章鱼图标由 imagegen 根据用户提供的视觉参考生成，重新生成图集不会覆盖图标。详见[素材说明](ARTWORK.md)；参考图和外部宠物图集不随包分发，用户自行导入的素材保留其各自许可。

`miniapp/client/vendor/markdown.mjs` 打包了 unified、remark-parse、remark-gfm 依赖树里 59 个 MIT 许可的包，各自的版权声明保留在 `miniapp/client/vendor/markdown.LICENSE.txt`，该文件由 `npm run build:markdown` 按 esbuild 实际打包的包清单生成。

麦芽糖素材由 Fectivnfy112357 贡献，同样采用 MIT 许可。麦芽糖通过 MiniMax 章鱼娘工坊工作流创作，使用 OpenAI imagegen 生成，再裁切、等比缩放和组装为透明图集；重新生成默认图集不会覆盖她。

MMX 章鱼娘素材由 antianqi 贡献，同样采用 MIT 许可。她通过本机部署的开源扩散模型出图与出视频，再由本地脚本抽帧、抠透明、落格拼成 v1 图集，无法用命令重新生成；重新生成默认图集不会覆盖她。
