# Source and distribution

Author: MiniMax ([MiniMax-AI](https://github.com/MiniMax-AI)). This is the 0.5.8 open-source edition of the MiniMax Pet MiniApp. It uses public MiniApp page APIs and contains no Host implementation. Public documentation, dependency URLs, and license notices have been prepared for this repository; private development references and acceptance records are not part of the package.

## Layout

- `sources/minimax-ai/minimax-pet/`: complete editable source, synthetic tests, development tools, and the dependency lockfile.
- `plugins/minimax-ai/minimax-pet/`: self-contained ready-to-install files.

Change the source first, stage the package, and copy the complete staged tree into the distribution directory. The installed plugin does not depend on the source directory or on `node_modules`.

## Reproduce

With Node.js 22 or later, from the source directory:

```sh
npm ci --ignore-scripts
npm test
npm run test:smoke
npm run package
npm run check:package
```

`package` stages an explicit runtime/documentation allowlist under `dist/package`. Synchronize that complete directory to `plugins/minimax-ai/minimax-pet` before `check:package`. The comparison covers every path and file byte, including images, code, metadata and licenses, and rejects links. Tests, the development lockfile, dependencies, tools, and local state are not staged.

The root `npm run check` validates package contracts through the repository's existing workflow. Run the source tests, HTTP smoke, staging and exact distribution comparison locally with the commands above; this package does not add or change repository CI jobs. Tests use synthetic data and temporary data directories; they do not need the user's real Host profile.

## Dependencies and artwork

Production JavaScript uses relative modules and Node built-ins. `jsdom` 24.1.3 is used only for DOM tests; the lockfile pins public npm registry URLs and integrity values. No dependency install or build step is required by the installed plugin.

The bundled mint robot atlas is original geometric artwork generated by `scripts/generate-pet-art.mjs` from Node built-ins. `npm run generate:art` reproduces the atlas without external images or fonts and preserves `icon.png`. The purple octopus icon is a separate transparent PNG generated with OpenAI imagegen from a user-provided visual reference; model generation is not deterministic, and that reference image is not bundled. These assets use the same MiniMax [MIT License](LICENSE) as the original code and documentation; see [ARTWORK.md](ARTWORK.md). No externally sourced pet spritesheet is bundled.

## Verification boundaries

The supported client baseline is MiniMax Code **3.1.6**. On 2026-10-26, the official [mainland China macOS](https://filecdn.minimax.chat/public/minimax-agent-prod/release/latest-mac.yml), [Global macOS](https://file.cdn.minimax.io/public/minimax-agent-prod/release/latest-mac.yml), and [mainland China Windows](https://filecdn.minimax.chat/public/minimax-agent-prod/release/latest.yml) production feeds listed 3.1.6, released on 2026-10-23. The corresponding release implementation was separately checked for session reads and observation, cancellation, capability checks, speech transcription, microphone declaration, and the click-through window handle. This is a confirmed released baseline, not a claim that 3.1.6 was the earliest version with each API.

The production feeds identify the distributed version; they do not establish that the plugin was installed or exercised on that client. This revision has not undergone 3.1.6 released-client GUI acceptance or real microphone recording/transcription. Runtime capability checks and permission checks remain necessary, and transcription also depends on the Host service and account access.

See `README.md` for tested and unverified environments. Static validation and a loopback smoke test do not prove GUI behavior on every platform, microphone recording, transcription, or official-market installation.
